# 재수종합반 시간표 관리 시스템 — 상세 설계서

- 문서 버전: 2.8
- 작성일: 2026-11-04
- 상태: Python 데스크톱 설계안 (구현 전)
- 프로젝트: academy-timetable
- 기반 운영 모델: 종로학원 재수종합반과 유사한 **반·요일·교시 중심 운영**
- 편성 방식: **수동 배치 + 자동 최적화 혼합형**
- 운영 형태: **Windows 및 macOS 동등 지원 / Python 오프라인 GUI 데스크톱 프로그램**
- UI: **GUI 우선(PySide6), 일반 사용자 터미널 명령 불필요**

> 주의: 이 문서는 공개적으로 알려진 재수종합반의 교시제 운영 방식을 참고한 독립 소프트웨어 설계안입니다. 종로학원의 공식 시스템이나 내부 업무 규칙을 재현했다고 주장하지 않습니다. 실제 교시 시간, 시수, 캠퍼스 규칙은 운영자가 직접 설정합니다. 예시 데이터는 모두 가상입니다.

## 1. 목표와 범위

### 1.1 목표

학원 관리자가 **Windows 또는 macOS의 설치형 Python GUI 프로그램**에서 학기별로 반, 교시, 과목별 시수, 강사, 강의실, 선택수업을 정의하고 다음 작업을 수행한다. 양쪽 운영체제에서 인터넷 연결 없이 동일한 핵심 기능을 제공한다.

1. 반별 주간 시간표를 수동으로 작성한다.
2. 수업 블록을 잠가 자동 편성에서 보호한다.
3. 아직 배정되지 않았거나 재배정이 허용된 수업을 자동 편성한다.
4. 강사·학생·반·강의실 충돌과 시수 미충족을 실시간 검증한다.
5. 생성된 배치안을 검토·수정하여 확정한다.
6. **국어 > 화법과 작문 / 언어와 매체처럼 대분류·세부 영역·선택 조합을 구분해 관리한다.**
7. 강사별·반별·강의실별 시간표를 조회하고 출력한다.
8. 정규 반복 시간표와 날짜별 휴강·보강·모의고사를 별도로 관리한다.

### 1.2 주요 사용자와 운영 형태

**MVP는 관리자 PC 한 대에서 실행하는 GUI 기반 단일 사용자 데스크톱 프로그램**이다. 일반 사용자는 Python 코드나 터미널 명령을 직접 입력하지 않는다. 웹 로그인, 서버, 온라인 계정 없이 로컬 DB 파일을 사용한다.

| 사용자 | 지원 범위 |
| --- | --- |
| 관리자 | 모든 정보 수정, 편성, 검토, 확정, 백업, 출력 |
| 강사 | 관리자가 내보낸 강사별 시간표를 열람 |
| 학생/학부모 | 관리자가 내보낸 시간표를 열람(개별 조회는 후속) |

- 첫 버전은 다중 PC 동시 편집/온라인 계정/웹 권한을 제공하지 않는다.
- 운영체제 사용자 계정과 파일 권한으로 로컬 파일 접근을 제한한다. 이는 앱 수준의 다중 사용자 인증을 대체하지 않는다.
- 향후 공동 편집이 필요하면 중앙 서버 구조로 별도 확장한다. SQLite 파일을 네트워크 공유 폴더에서 다중 PC 동시 편집용으로 쓰지 않는다.

### 1.3 우선 구현 범위(MVP)

- 교시표/학기/반/강사/과목/강의실 관리
- 반별 과목 시수 관리
- **과목 계층(국어 > 화작/언매 등)과 상호배타적 선택 영역 등록 및 GUI 표시**
- **강사별·세부 과목별 배정 시수표**(강사명, 수강기호, 과목별 교시 수, 합계 및 총합, Excel 출력)
- **과목별 동시 편성 그룹(A / B·C 등)과 주간 교시·요일별 우선 배치 규칙**
- 주간 반복 시간표 수동 편집 및 잠금
- 충돌 검증과 저장
- 기본 자동 편성 및 미배치 사유
- 배치안 검토 및 게시(확정)
- 반별/강사별 보기와 인쇄

후속 확장: 학생별 선택수업, 특강·모의고사, 날짜별 예외 일정, 세밀한 알림·통계, 선택적 다중 PC 연동.

### 1.4 비목표

- 출결, 학원비 수납, 성적 분석을 첫 버전에 포함하지 않는다.
- 특정 학원의 내부 시수·강사 배정 규칙을 추정하여 기본값으로 강제하지 않는다.
- 자동 편성 결과를 검증 없이 즉시 운영 시간표에 반영하지 않는다.
- 브라우저 UI, REST API, 웹 서버, 온라인 계정은 MVP에 포함하지 않는다.

## 2. 용어와 기본 원칙

| 용어 | 의미 |
| --- | --- |
| 캠퍼스(Academy) | 데이터를 관리하는 학원 또는 지점 |
| 학기(Term) | 하나의 시간표가 적용되는 운영 기간 |
| 반(Cohort) | 자연계 A반 등 정규수업의 기본 학생 집합 |
| 교시(Period) | 운영자가 설정한 수업 시간 슬롯. 예: 08:40~09:30 |
| 과목 시수(Quota) | 반·과목별 일주일에 필요한 수업 교시 수 |
| 배정 항목(Entry) | 요일/교시에 과목·강사·강의실을 배치한 기록 |
| 고정(Locked) | 자동 편성 및 자동 재편성에서 변경할 수 없는 항목 |
| 시간표 버전(Version) | 운영 시간표와 분리된 편집·검토·게시 단위 |
| 선택수업 그룹(Elective Group) | 소속 반과 별개로 학생을 묶어 수업하는 집합 |
| 예외 일정(Exception) | 특정 날짜에만 적용되는 휴강·보강·시험 |

**중요 불변식**

1. 정규수업은 원칙적으로 한 반에 같은 시각 하나만 배정한다.
2. 강사 한 명은 같은 시각에 둘 이상의 수업 또는 감독 업무를 담당할 수 없다.
3. 강의실 한 곳은 동일 시각에 중복 점유할 수 없다.
4. 학생은 서로 다른 반·선택수업을 포함해 같은 시각에 두 수업을 들을 수 없다.
5. 확정된 버전은 직접 수정하지 않으며 복사한 초안에서 수정한다.
6. 잠금된 항목은 자동 편성기가 이동·삭제·변경하지 않는다.
7. 충돌 검사는 교시 번호뿐 아니라 실제 시작·종료 시각의 구간 교집합으로 판단한다.
8. 점심·저녁 등 수업 불가 교시는 일반 수업을 배정할 수 없다.

## 3. 재수종합반 교시 운영 모델

### 3.1 확정 기본 교시표 (사용자 제공)

사용자가 제공한 다음 **11개 수업 교시**를 새 학기 생성 시 초기 기본 템플릿으로 사용한다. 월~금에 동일한 시간대를 기본 적용하되 운영 요일 및 학기별 교시표는 GUI에서 변경할 수 있다. 기존에 문서에 포함된 08:40 시작 시간표는 참고용 구버전 예시이며 이 표를 대신할 수 없다.

| 교시 | 시작 | 종료 | 수업 시간 | 다음 교시 전 휴식 |
| --- | --- | --- | --- | --- |
| 1교시 | 08:30 | 09:20 | 50분 | 10분 |
| 2교시 | 09:30 | 10:20 | 50분 | 10분 |
| 3교시 | 10:30 | 11:20 | 50분 | 10분 |
| 4교시 | 11:30 | 12:20 | 50분 | **70분(점심)** |
| 5교시 | 13:30 | 14:20 | 50분 | 10분 |
| 6교시 | 14:30 | 15:20 | 50분 | **20분 휴식** |
| 7교시 | 15:40 | 16:30 | 50분 | 10분 |
| 8교시 | 16:40 | 17:30 | 50분 | **70분(저녁)** |
| 9교시 | 18:40 | 19:30 | 50분 | 10분 |
| 10교시 | 19:40 | 20:30 | 50분 | 10분 |
| 11교시 | 20:40 | 21:30 | 50분 | 종료 |

**시간대 그룹**: 오전 1~4교시 / 오후 5~8교시 / 야간 9~11교시. 각 교시 실제 수업시간은 50분이다. 점심·저녁·20분 휴식은 수업 교시가 아니라 교시 사이의 비수업 시간으로 표시한다.

**2교시 연강 기본 정책과 연결**
- 일반 과목은 연속된 2개 교시를 하나의 묶음으로 사용한다. 시작 가능한 쌍: **1~2, 2~3, 3~4, 5~6, 6~7, 7~8, 9~10, 10~11**.
- 점심을 가로지르는 **4~5교시** 및 저녁을 가로지르는 **8~9교시**는 **연강 불가**다. 6~7교시 사이의 20분 휴식은 허용되는 교시 간 휴식으로 보고 기본적으로 **6~7교시 연강 가능**으로 한다. 다만 학원 운영 정책에 따라 GUI에서 별도 금지할 수 있다.
- 영어는 **1교시 단독**을 기본으로 하므로 1~11교시 중 사용 가능한 단일 슬롯에 배치할 수 있다.
- 연강 시작 교시 및 종료 교시는 반드시 같은 요일·동일한 과목/강사/반/강의실을 공유하며, 자동 편성기와 수동 편집기 모두 하나의 수업 묶음으로 처리한다.
- 시간표 GUI와 Excel/PDF 출력에 **11개 교시의 정확한 시작/종료 시간**을 표시한다. 비수업 시간은 별도 구분선/음영/간격으로 표현하고, 점심·저녁을 정규 교시로 잘못 계산하지 않는다.
- 총 11교시 중 일반 과목 2교시 묶음만으로는 하루 전체를 빈틈없이 채울 수 없을 수 있다. 이를 자동으로 오류로 처리하지 않으며, 영어·자습·공통 활동·허용된 예외 수업 등과 조합한다. 검증은 반·과목별 요구 시수와 실제 점유 교시를 기준으로 한다.

**시각 저장 및 검증**
- `period_slots`에 교시 번호, `start_minute`, `end_minute`를 분 단위로 저장한다. 교시별 정확히 50분인지 초기 기본 템플릿에서 검증한다.
- 점심/저녁 경계 및 수업연강 허용 여부는 슬롯 간 구간 정책으로 검증한다. 모든 연속 교시를 단순히 `period_order + 1`이라는 이유만으로 연결하지 않는다.
- 시간표/자동 편성/시수표 모두 이 교시표를 단일 기준 정보로 참조한다. 동일한 2교시 연강은 시수 집계에서 **2교시**로 계산한다.
- 교시표 변경은 학기·시간표 버전의 영향 범위와 기존 고정 수업의 유효성을 재검증한 후 반영한다.

| REGULAR | 반 전체 | 과목 시수 충족, 담당 강사 지정 |
| ELECTIVE | 선택 학생 그룹 | 실제 학생 충돌 검사 |

| BREAK | 점심·저녁 등 | 수업 배정 금지 |

### 3.3 대과목·세부 영역·선택 과목 설계

**국어(상위 과목)**와 **화법과 작문(화작) / 언어와 매체(언매)**를 독립 과목처럼 무작정 배치하면 같은 학생에게 중복 수업이 생기거나 국어 시수가 이중 계산될 수 있다. 따라서 **상위 과목 / 세부 과목 / 선택 그룹 / 학생 또는 반의 선택**을 구분한다.

| 상위 과목 | 세부 과목 예시 | 선택 구분 예시 |
| --- | --- | --- |
| 국어 | 독서, 문학 | 공통 영역(운영 과정에 따라 조정) |
| 국어 | 화법과 작문, 언어와 매체 | 같은 선택 그룹 안의 대안 |
| 수학 | 수학Ⅰ, 수학Ⅱ, 미적분, 확률과 통계, 기하 | 과정·반·학생별 공통/선택 지정 |
| 탐구 | 물리학, 화학, 생명과학, 지구과학 등 | 학생별 수강 선택 |
| 영어 | 독해, 듣기, 문법 등 | 운영자가 지정하는 세부 영역 |

> 표는 **과목 분류를 위한 가상 예시**이며 연도별 교육과정·수능 선택 구조나 특정 학원의 실제 편성 규칙을 의미하지 않는다. 과목 트리와 선택 여부는 관리자가 학기별로 설정한다.

**선택 정책**
- 상위 과목은 통계/색상/묶음 용도이고 실제 배정은 **구체적인 세부 과목 ID**를 참조한다. 일반적인 국어 공통수업은 별도의 '국어 공통' 항목으로 모델링할 수 있다.
- 예: 동일한 선택 그룹 **국어 선택**에서 화작 또는 언매 중 하나를 선택하도록 설정할 수 있다. 이 규칙은 과정별로 설정하며 모든 학원에 강제하지 않는다.
- 한 반 안에 화작·언매 학생이 섞이면 **같은 선택 블록 시간**에 서로 다른 강사·강의실로 병렬 편성할 수 있다. 각 그룹의 실재 학생 구성에 따라 충돌을 판단한다.
- 선택 학생 명단이 아직 없다면 그룹 단위 수강 범위만 임시 관리할 수 있지만 **학생별 중복 없음이 검증된 것으로 표시하지 않는다**. 학생 선택 데이터를 등록한 이후에만 학생 단위 검증을 완료로 표시한다.
- 편성 시수는 **상위 과목의 총 시수**와 **세부 과목별 시수**를 중복 합산하지 않는다. 하나의 시수 기준이 자식 영역을 포함하는지 설정한다. 예: 국어 총 8교시 = 공통 6교시 + (화작 또는 언매) 2교시. 학생 선택 그룹을 병렬 운영하면 강사 점유는 각 그룹마다 계산하되, 한 학생의 국어 시수는 실제 자신이 수강한 교시만 계산한다.
- 시간표 셀에는 가능한 한 **국어 · 언매**, **국어 · 화작**처럼 실제 과목을 표시하고, 좁은 화면에서는 **국어(언매)** 등으로 축약한다.
- 전체 조회와 Excel 출력에도 과목명/세부 영역명/선택 그룹을 별도 데이터로 보존한다.

### 3.4 세부 영역 편성 예시

| 수요일 4교시 | 대상 | 과목 | 강사 | 강의실 |
| --- | --- | --- | --- | --- |
| 선택 블록 A | 화작 선택 학생 | 국어 > 화법과 작문 | 강사 A | 301호 |
| 선택 블록 B | 언매 선택 학생 | 국어 > 언어와 매체 | 강사 B | 302호 |

동시간에 병렬 배정해도 학생 명단이 상호배타적이고 강사/강의실이 각각 다르면 정상이다. 반 전체에 국어 한 과목으로 뭉뚱그려 저장하거나, 두 그룹을 학생 모두가 듣는 수업으로 계산하지 않는다.

### 3.5 기본 수업 길이 — 일반 과목 2교시 연강, 영어 1교시

**기본 편성 규칙(사용자 지정):** 재수종합반 수업은 원칙적으로 **연속된 2교시를 하나의 수업 묶음**으로 편성한다. **영어는 1교시 단위로 편성**한다.

| 수업 구분 | 기본 수업 묶음 길이 | 편성 예시 |
| --- | --- | --- |
| 국어(공통·화작·언매 포함) | 2교시 연강 | 1~2교시 또는 3~4교시 |
| 수학(대수·미적분 등) | 2교시 연강 | 5~6교시 |
| 탐구·사회·과학 및 기타 일반 과목 | 2교시 연강 | 1~2교시 |
| **영어 및 영어 세부 과목** | **1교시** | 1교시 단독, 3교시 단독 |
| 자습·조회·식사·시험·특강 등 | 수업 유형별 별도 규칙 | 관리자가 지정 |

**'2시간 연강'은 이 프로그램의 교시제 문맥에서 '연속 2교시'로 해석한다.** 교시당 50분이라면 수업 실시간은 100분이며, 교시 사이 휴식은 템플릿에 따른다. 별도의 실제 120분 수업이 필요한 경우에는 총 분 수를 기준으로 교시표/특강을 따로 정의한다. 영어 1시간 수업 역시 우선 1교시로 해석한다.

**규칙 적용 우선순위**
1. 학기 기본값: 일반 과목 2교시, 영어 1교시.
2. 상위 과목(예: 국어, 영어)의 수업 길이를 하위 세부 과목이 상속한다.
3. 운영자가 특정 세부 과목이나 수업 유형에 길이를 명시하면 그 값을 적용한다(예외 사유 기록).
4. 반별 특수 수업/고정 교시의 명시적 예외가 있다면 이를 최우선으로 적용한다. 단, 강사·강의실·학생 중복 검증은 예외로 해제하지 않는다.

**2교시 연강의 불변조건**
- 첫째·둘째 교시는 같은 요일의 연속 교시로서 해당 시간표의 정규수업 허용 슬롯이어야 한다.
- 두 교시 모두 **동일 수업 묶음 ID**를 공유하고 과목(세부 영역), 강사, 수강 대상, 강의실이 일치해야 한다. 수업 묶음 사이를 다른 과목으로 분할할 수 없다.
- 교시 사이에 일반 쉬는 시간이 있는 것은 허용하지만, **점심·저녁·자습 전용·시험·휴식 고정 슬롯을 가로질러** 2교시로 묶을 수 없다.
- 강사·학생·강의실은 묶음 전체 시간대 동안 동시에 점유되므로 모든 점유 교시/실제 시각에 대해 충돌 검사한다.
- 수동으로 이동하거나 잠글 때도 **묶음 전체를 원자적으로** 이동·잠금·해제한다. 개별 교시 삭제나 교사 교체는 명시적인 분리/예외 승인 없이 허용하지 않는다.
- 영어 1교시는 한 블록으로 취급하며, 영어 두 개의 독립 수업이 인접해도 자동으로 2교시 연강 수업 하나로 합치지 않는다.

**주당 시수와 묶음의 관계**
- 예: 국어 주당 6교시는 기본적으로 **2교시 묶음 × 3회**, 영어 주당 5교시는 **1교시 × 5회**로 생성한다.
- 일반 과목이 주당 홀수 교시라서 2교시로 나누어떨어지지 않으면 기본 정책에서는 완전 편성을 불가로 표시하고, 사용자가 명시적으로 '남은 1교시 단독 수업 허용' 등 예외를 지정했을 때만 혼합 길이로 생성한다.
- 강사 배정 시수표는 **묶음 수가 아닌 실제 점유 교시 수**로 집계한다. 일반 2교시 연강 1회=2시수, 영어 1교시 1회=1시수.
- 연강 묶음이 동일 시간표에 중복 저장되어도 교시 점유는 정확히 한 번만 집계한다.

**확정 교시표(3.1절) 기준 예시:** 수학은 월요일 1~2교시(08:30~10:20, 중간 휴식 10분), 영어는 화요일 3교시(10:30~11:20)에 배정한다. 모든 교시의 수업시간은 50분이다.

### 3.6 과목별 동시 편성 그룹 (반 묶음)

**사용자 확정 규칙:** 과목별로 반을 그룹으로 나누고, **같은 과목의 같은 그룹 멤버는 요일·시작/종료 교시가 같아야 한다.** 반면 **다른 교과의 그룹은 그룹번호가 같아도 독립적**이며 같은 시간대에 병렬 편성이 가능하다. 다른 그룹도 자원 충돌이 없다면 동시간 배치할 수 있다.

예시: 과목 '국어 > 문학'의 **1그룹=A반**, **2그룹=B반+C반**. 2그룹의 월요일 1~2교시 문학 2T 수업은 반드시 동시 편성한다.

| 요일/교시 | 과목 | 그룹 | 반 | 수업 길이 | 강사(수강기호 예시) |
| --- | --- | --- | --- | --- | --- |
| 월 1~2교시 | 국어 > 문학 | 2그룹 | B반 | 2교시 연강 | 국현 |
| 월 1~2교시 | 국어 > 문학 | 2그룹 | C반 | 2교시 연강 | 국문 |
| 별도 편성 가능 | 국어 > 문학 | 1그룹 | A반 | 2교시 연강 | 반 담당 강사 |

- 2그룹에는 **하나의 동시 수업 세션**이 존재하고 B반·C반별 개별 수업 배정 항목은 동일한 세션 시간을 참조한다.
- B/C는 **같은 시간**이지만 강사·강의실·수강기호는 서로 별도로 지정한다. 서로 다른 강사/강의실 및 반 자원 중복 조건을 모두 만족해야 한다.
- 같은 그룹에 속한 반을 어느 하나만 이동/삭제해 그룹의 동시성을 깨뜨릴 수 없다. **전체 그룹 세션을 하나의 작업으로 이동·잠금·해제**한다. 강사/강의실 변경은 멤버별로 할 수 있으나 전체 시간 충돌 검사는 다시 수행한다.
- 동시 편성 그룹은 **선택과목 택1 그룹(화작/언매 등)**과 다른 기능이다. 택1은 학생의 수강 대상을, 동시 편성은 여러 반의 **시간 일치**를 의미한다.
- 기본적으로 동시 편성 그룹의 모든 멤버는 **같은 세부 과목·주간 횟수·연강 길이**를 요구한다. 불일치하면 자동 생성 전에 오류를 내고 어떤 반의 시수가 불일치하는지 표시한다.
- 2그룹의 월요일 1~2교시를 수동 고정하면 B·C의 문학 수업 모두 고정된다. 다른 그룹인 A반의 문학 수업은 해당 잠금의 영향을 받지 않는다.
- 그룹 구성 및 수강기호는 학기마다 변경 가능하고, 기존 확정 시간표는 버전별로 보존한다.

**교과가 다른 동시 그룹의 같은 시간 병렬 배치**

| 사례 | 결과 | 이유 |
| --- | --- | --- |
| 월 1~2교시 국어 문학 2그룹 B·C + 수학 2그룹 D·E | **허용** | 다른 반·학생·강사·강의실 사용 |
| 월 1~2교시 국어 문학 2그룹 B·C + 영어 1그룹 A | **허용** | 자원 중복이 없는 다른 교과 |
| 월 1~2교시 국어 문학 1그룹 A + 국어 문학 2그룹 B·C | **허용** | 그룹이 서로 독립적이고 자원 중복 없음 |
| 월 1~2교시 국어 문학 2그룹 B·C + 수학 2그룹 B·D | **불가** | B반 전체가 두 정규수업에 동시에 참여 |
| 같은 시간 다른 과목/그룹인데 담당 강사 또는 강의실이 동일 | **불가** | 실제 공유 자원이 시간 충돌 |

- 그룹 식별에는 **학기 ID + 과목 ID + 그룹 ID**를 사용한다. 과목이 다르면 '2그룹' 표시명이 같아도 **동일 그룹으로 합치거나 시간대를 묶지 않는다**.
- **동시 편성 의무는 같은 synchronized_group 내부에만 적용**한다. 다른 과목이나 다른 그룹 간에는 시간 불일치 의무도, 시간 겹침 금지 의무도 없다.
- 충돌 판단은 그룹명/번호가 아니라 강사·강의실·반 또는 실제 수강 학생 집합의 점유 시간 교집합만으로 수행한다.
- 같은 반 전체수업끼리는 서로 다른 과목이어도 같은 시간 배정 불가. 단, 같은 반의 **서로 다른 선택수업 학생 집합**이 분리돼 있고 강사·강의실도 다른 경우 병렬 수업이 가능하다.
- 다른 교과라는 이유로 실제 강사·실·학생 충돌 검사를 생략하지 않는다.

### 3.7 평일 교과별 편성 시간 규칙 (월~금)

**운영 요일은 월요일~금요일만 사용한다.** 주말 교시를 기본 정규 시간표의 후보에서 제외한다(다른 운영 과정은 학기 설정으로 확장 가능).

| 대상 | 기본 배정 시간(엄격) | 예외 및 선호 | 수업 길이 |
| --- | --- | --- | --- |
| 국어(문학/화작/언매 등) | **월~금 1~4교시** | 오전에 배정 불가능하면 승인된 예외만 허용 | **2교시 연강** |
| 수학(대수/미적분 등) | **월~금 1~4교시** | 오전에 배정 불가능하면 승인된 예외만 허용 | **2교시 연강** |
| 영어 및 영어 세부 과목 | **월~금 1~4교시** | 불가능한 경우 **5교시 배정 가능, 반당 주 1개 요일 이내** | **1교시** |
| 통합사회 | **월~금 5~6교시** | **화요일·목요일 우선 배치** | **2교시 연강** |
| 통합과학 | **월~금 5~6교시** | **화요일·목요일 우선 배치** | **2교시 연강** |
| 그 외 과목 | 기존 수업 길이 및 개인별 제약 | 교시표/운영자 지정 | 기본 2교시 |

**국수영의 5교시 예외 해석과 안전성**

1. 평상시에는 국어·수학·영어 모두 **1~4교시 이내에서 수업을 완전히 마쳐야** 한다.
2. 오전만으로 가능하지 않으면 **반당 월~금 중 최대 1개 요일**에 국수영의 **5교시 점유**를 허용한다. 단순 선호 점수가 아니라 예외가 적용되었다는 사실을 GUI에서 표시하고 검토하도록 한다.
3. **영어(1교시)**는 5교시에 단독 배치할 수 있다.
4. **국어·수학(2교시)**은 4~5교시 연결이 점심시간을 가로질러 금지되며, 5~6교시는 6교시까지 사용하므로 **'5교시까지만' 허용된 예외 범위를 초과한다**. 따라서 기본 정책에서는 이 두 과목을 5~6교시로 자동 이동시키지 않는다.
5. 국어·수학의 오전 배치가 불가능하면 **미배치 사유를 표시**하고, 관리자가 **명시적으로 추가 범위(예: 5~6교시 2T)를 승인하는 별도 예외**를 설정했을 때만 허용한다. 이 추가 예외는 기본값이 아니다.
6. 동시 편성 그룹의 수업이 예외 시간을 차지한다면 **그룹의 모든 반**에 동일하게 적용되고, 각 반의 주 1개 요일 한도를 각각 검사한다.

**통합사회/통합과학의 5~6교시 규칙**

- 두 과목의 각 정규 수업은 **5교시 시작, 6교시 종료**의 연속 2교시 묶음만 유효하다. 5교시만 단독 배정하거나 6~7교시 등으로 이동하지 않는다.
- 화요일/목요일 배치는 **선호 조건(soft constraint)**이다. 해당 요일이 비어 있지 않다면 월/수/금 5~6교시에 배치하는 것은 가능하다. 관리자가 화·목 선호 중요도를 조절할 수 있다.
- 같은 반의 통합사회와 통합과학은 동일 요일 5~6교시에 중복될 수 없다. 강사·강의실 및 동시 그룹의 모든 구성원도 함께 검사한다.
- 국어·수학의 특별 5~6교시 예외를 허용하는 경우 통합사회/통합과학과 같은 반의 자원을 경쟁하므로 배치 가능한지 재검증해야 한다.

**편성 엔진 단계**
1. 과목별 그룹 멤버/시수를 검증하고 동시 세션 변수를 만든다.
2. 1~4교시 후보를 중심으로 국어·수학·영어를 우선 배정한다.
3. 통합사회·통합과학은 5~6교시 후보만 사용하고 화·목에 선호 점수를 준다.
4. 완전 해가 없을 때 영어 등의 **5교시 예외를 주 1개 요일 이내**로 재탐색한다.
5. 어떤 필수 조건도 임의로 완화하지 않고 남은 불가 원인과 예외 승인 필요 여부를 결과 화면에 제시한다.

~~~mermaid
flowchart TD
~~~

### 4.1 신규 시간표 생성

1. 학기와 적용 교시표를 선택한다.
2. 반을 생성하고, 반별 과목 시수(예: 국어 6, 수학 9)를 입력한다.
3. 과목별 배정 가능 강사와 강사별 근무 가능 시간/휴무를 입력한다.
4. 수업 가능 교시, 연속 수업 조건, 강의실 수용 인원과 시설을 설정한다.
5. 관리자가 특정 교시를 직접 배치하고 필요한 항목은 잠근다.
6. 자동 편성 범위를 선택하고 배치안을 생성한다.
7. 미배치 사유와 충돌을 확인하여 수동 조정한다.
8. 필수 검증을 통과하면 확정 후 출력한다.

### 4.2 재편성 동작

- **미배치만**: 현재 배정을 모두 유지하고 비어 있는 요구 수업만 탐색한다.
- **잠금 해제 항목 포함**: 잠금 항목은 유지하고 일반 항목은 이동할 수 있다.
- **전체 재편성(잠금 제외)**: 잠기지 않은 항목을 재탐색한다.
- 실행 결과는 별도 배치안으로 저장하며 사용자 승인 전에는 원본 버전을 변경하지 않는다.
- 관리자가 수동으로 만든 항목은 기본 잠금을 권장하되 해제할 수 있게 한다.

**구현 세부 사항**
- 시간표: QTableView + QAbstractTableModel. 색상과 잠금 아이콘은 데이터 역할 또는 delegate로 표시한다.

- 잠금·수정·삭제·복사·실행 취소: QUndoStack 및 명령 객체 사용.
- 반별/강사별/강의실별 화면은 동일한 DB 배정 정보를 다른 관점으로 표시한다.
- 충돌은 해당 셀에 표시하고 하단 패널에 원인·해결 후보를 안내한다.
- QPrintPreviewDialog 및 QPrinter로 인쇄 미리보기와 PDF 출력.

### 5.2 자동 편성의 GUI 응답성

자동 편성(CP-SAT)은 메인 GUI 스레드에서 수행하지 않는다. QThread + Worker 또는 별도 프로세스에서 실행하고 Qt Signal/Slot으로 진행 상태·완료·취소·오류를 전달한다. 워커에서 GUI 위젯을 직접 변경하지 않는다. 진행 중 원본 초안을 보존하고 완료 후 검토 대화상자를 연다.

### 5.3 GUI 필수 사용 시나리오

**프로그램 실행부터 시간표 저장·내보내기까지 모든 일반 사용자의 핵심 기능은 GUI로 수행한다.** 개발자용 명령행은 일반 사용자에게 요구하지 않는다.

| 작업 | GUI 화면 | 조작 | 처리 결과 |
| --- | --- | --- | --- |

- 주간 교시 그리드, 클릭/더블클릭 배정, 드래그 이동, 잠금, 검색/필터, 다이얼로그를 제공한다.
- 드래그를 쓰기 어려운 사용자도 버튼 및 키보드로 수업을 이동할 수 있어야 한다.
- 저장되지 않은 변경이 있을 때 학기 전환/창 종료 전에 저장·버리기·취소를 확인한다.
- 삭제·대규모 재편성·시간표 확정·DB 복원 전 영향 범위와 확인 대화상자를 표시한다.
- 충돌 발생 시 관련 반·강사·교시·강의실 및 해결 방향을 한국어로 안내한다.
- Windows는 .exe(또는 설치 프로그램), macOS는 .app을 더블클릭하면 별도 터미널 창 없이 GUI가 열리는 형태로 패키징한다.
- 편성은 백그라운드에서 실행하고 완료·실패·취소를 Qt Signal로 표시한다.

### 5.4 엑셀 저장 GUI 상세

1. 시간표 화면에서 **[엑셀 저장]** 버튼을 클릭한다.
2. ExportDialog에서 [반별] [강사별] [강의실별] [전체]를 선택한다.
3. 하나 이상의 대상 또는 [모두 선택]을 지정한다.
4. 출력 버전, [전체 배정 목록 포함], [시수 요약 포함], [강사명 표시], [강의실 표시]를 선택한다.
5. [저장] 후 PySide6 QFileDialog에서 파일 이름과 저장 위치를 지정한다.
6. Python openpyxl이 수정 가능한 셀·시트·A4 가로 인쇄 설정이 포함된 .xlsx 파일을 생성한다.
7. 성공 시 파일 경로를 표시하고, 실패 시 파일 잠김/쓰기 권한 등 원인을 안내한다.

Excel 파일에서 수정한 정보는 SQLite 원본에 자동 반영되지 않는다. 엑셀 가져오기는 별도 후속 기능이다.

### 5.5 세부 과목 선택 GUI 요구사항

- **[과목 관리]**: 대분류 트리(국어/수학/탐구 등) 안에 세부 과목 추가·수정·비활성화. 상위 과목과 세부 과목을 색상/들여쓰기로 구분한다.
- **[선택 그룹 관리]**: 예를 들어 '국어 선택' 그룹을 만들고 화작·언매를 **택1**로 설정한다. 선택 그룹 규칙은 필수/선택, 1개 또는 지정 개수 선택으로 설정 가능해야 한다.
- **[반·학생 선택]**: 같은 반에서도 학생마다 수강 영역을 개별 등록할 수 있게 확장한다. MVP 단계에는 반별 선택 그룹 및 선택 영역 관리부터 제공하되 개인별 배정 누락 시 경고한다.
- **[과목 시수]**: 국어 총 시수/세부 영역 시수를 함께 보여주면서 **총계에 포함되는 기준**을 표시하고 이중 계산 여부를 경고한다. 일반 과목의 홀수 필수 시수는 별도 1교시 예외 설정이 없으면 사전 경고한다.
- **[시간표 편집]**: 셀 클릭 시 [상위 과목] → [세부 과목] 순서로 선택하고, 선택수업의 경우 [선택 그룹]과 해당 학생 그룹도 지정한다.
- **[시간표 표시]**: '국어(화작)'·'국어(언매)' 또는 '국어 선택'으로 표시. 셀 상세정보에는 풀네임, 선택 학생 수, 강사와 강의실을 표시한다. 2교시 연강은 연결/병합 블록으로 표시하고 영어 1교시는 독립 블록으로 표시한다. 기본 **1~11교시**와 3.1절의 정확한 시각을 좌측 시간 열 및 출력에 반영하고 점심/저녁 경계를 시각적으로 구분한다.
- **[자동 편성]**: 공통수업과 선택 블록의 구분, 두 선택 그룹의 병렬 편성, 학생·강사·강의실 충돌을 안내한다. 학생 명단이 없으면 학생 충돌 검증은 '미확인'으로 표시한다.
- **[Excel 출력]**: '국어 / 언어와 매체'처럼 세부 과목까지 구분하고, 시수 요약과 전체 배정 목록에 상위 과목과 세부 과목 컬럼을 제공한다.

```text
│국어 │이OO   │국김    │     0 / 2 / 1 / ...          │  3  │
│수학 │박OO   │수고    │     0 / 0 / 0 / ...          │  4  │
├─────┴───────┴────────┴───────────────────────────────┼─────┤
│ 과목 열별 합계 / 전체 합계                             │  8  │
└───────────────────────────────────────────────────────┴─────┘
```

**GUI 동작**
- 교과명을 기준으로 강사 목록을 묶고 확장/축소하며, 강사명이나 수강기호로 검색·필터한다.
- 열은 운영자가 등록한 세부 과목으로 **동적 생성**한다. 이미지 예시의 화법과언어·독서와작문·문학·대수·미적분1·확률과통계·영어·통합사회·통합과학에 고정하지 않는다.
- 시수 셀을 선택하면 해당 강사의 배정 내역(반, 요일, 교시, 세부 과목, 강의실)을 하단 패널 또는 팝업에 표시한다.
- 반별 시간표를 수동 변경하거나 자동 편성안을 적용하면 시수표를 즉시 **재계산**한다. 초안과 확정본, 학기 및 주간 기준을 구분한다.
- [목표 대비] 표시를 선택하면 강사별 계획 시수, 실제 시수, 잔여·초과 시수를 보여준다. 미등록 목표는 0으로 해석하지 않고 '미설정'으로 표시한다.
- 자동 편성 중·결과 검토 중에도 목표 초과 강사, 미달 강사, 최대 일일/주간 교시 제한을 경고하고 상세 배정으로 이동할 수 있게 한다.
- 표는 QTableView + QAbstractTableModel로 구현하며 세부 과목 수가 많아지면 가로 스크롤, 상단/좌측 고정 영역 또는 적절한 화면 분할을 사용한다.
- 시수표 조회는 실제 시간표 배정 정보에서 생성하며 **다른 화면에서 동일한 시수를 다시 수동 입력하지 않는다**. 계획 목표는 별도로 등록 가능하다.

**계산 기준**
- '1시수'는 기본적으로 **시간표에서 배정된 1교시**로 정의한다. 실제 50분/60분 등 분 단위 환산이 필요하면 별도 집계 옵션으로 제공한다.
- 연속 2교시 수업은 2시수로 계산한다. 동일 수업을 여러 반 화면에서 중복 참조하더라도 강사가 한 번 담당한 교시만 세며, 공동 강의·분반은 각 강사의 실제 책임 구간을 명시적으로 기록한다.
- 담당 강사가 없는 자습/공통 일정은 강사 배정 시수에 포함하지 않는다. 자습 감독 시수는 기본 분리 집계하며 운영자 설정으로 포함 여부를 결정한다.
- 한 강사가 **여러 수강기호**를 사용하면 강사×수강기호로 구분한 행과 강사별 합산 보기를 모두 지원한다. 같은 배정 항목이 여러 집계 행에 중복 포함되지 않게 한다.
- 행 합계는 그 강사의 과목별 실제 배정 시수 합, 열 합계는 모든 강사의 해당 세부 과목 담당 시수 합, 우하단 합계는 모든 행 합계의 합이다. **2교시 연강 1회는 2시수**, 영어 1교시 1회는 1시수로 계산한다.
- **상위 과목과 세부 과목은 같은 시수를 중복 합산하지 않는다.** 국어 공통/화작/언매 등 실제 배정된 말단 과목 또는 지정 집계 기준으로 통일한다.
- 부하 목표의 합계는 실제 배정 합계와 별도로 표시한다. 시간표 버전/학기/기간이 바뀌면 두 값의 비교 기준을 일치시킨다.

**검증**: 행 합계=과목별 합, 열 합계=행별 합, 전체 합계=양쪽 집계 일치, 강사 상세 배정 수 합계와 표 값 동일을 자동 테스트한다.

### 5.7 동시 그룹·시간대 제약 GUI

- **[과목별 동시 편성 그룹]**에서 과목과 학기를 선택해 1그룹(A), 2그룹(B·C)처럼 그룹을 추가한다. 반 멤버를 체크박스로 고르고 반별 강사·강의실·수강기호를 지정한다.
- 시간표에서 그룹 표시(예: '국어·문학 / 2그룹 B+C')를 클릭하면 구성원 전체의 해당 주간 수업을 강조한다. 한 멤버만 옮기려 할 경우 '이 수업은 B·C 동시 편성입니다. 그룹 전체 이동' 확인을 요구한다.
- 국어 2그룹과 수학 2그룹은 **교과명과 그룹번호를 함께 표시**하여 구분한다. 서로 다른 과목 그룹의 시간이 같다는 이유만으로 충돌 경고를 표시하지 않는다.
- **[교과 시간대 규칙]**에서는 국수영 1~4교시 우선, 영어 5교시 주 1개 요일 예외, 통합사회/과학 5~6교시 고정, 화·목 우선 선호를 표시한다.
- 예외 사용 여부와 이유를 입력받고, 위반 항목을 별도 목록으로 보여준다. 연강을 자동으로 분할하거나 잠금된 그룹을 독립 이동시키지 않는다.
- 자동 편성 결과에는 **동시 그룹 일치 검사**, 오전 국수영 배치율, 5교시 예외 요일 수, 통합사회/과학의 화·목 배치 여부를 표시한다.

**관계/무결성 주의**

- 모든 엔터티 참조는 같은 캠퍼스/학기에 속하는지 확인한다.
- cohort_id 또는 elective_group_id 중 정확히 하나를 사용하는 수업과 전 캠퍼스 공통일정을 구분하기 위해 대상 유형(audience_type)을 명시적으로 둔다.
- 교시표의 day_of_week 및 실제 시간은 연결된 학기의 설정과 일치해야 한다.
- 복수 교시에 걸친 수업은 점유하는 교시 전체가 유효하고 수업 허용 상태여야 한다.
- 시간표 버전이 달라지면 배정 항목도 버전별로 독립 저장한다.
- 특정 날짜 예외를 적용한 실제 일정 조회에서는 반복 시간표보다 예외의 우선순위가 높다.
- 정규반의 학생 명단과 선택수업 등록 학생 명단을 조합해 실질 학생 충돌을 계산한다.
- 세부 과목의 parent_subject_id는 같은 학원 내 과목만 참조하고 순환 참조를 금지한다. 삭제 대신 비활성화하여 기존 시간표 기록을 보존한다.
- 선택 그룹의 선택 개수 제약(예: 화작/언매 택1)은 지정한 대상(학생 또는 반)별로 확인한다.
- 상위 과목과 하위 과목을 모두 시수표에 등록했다면 aggregation_policy에 따라 총계에서 중복 가산하지 않는다.
- 선택 블록의 실제 수강 대상을 연결해 같은 반의 상호배타적인 수업은 병렬 가능하게 하면서 개별 학생의 동시 수강 중복은 금지한다.
- **강사별 실배정 시수는 timetable_entries에서 계산한 읽기 전용 집계값**이며 별도 중복 저장하지 않는다. 목표 시수만 teacher_load_targets에 저장할 수 있다.
- `session_group_id`는 연속 2교시를 하나의 수업으로 취급하는 논리 식별자다. 저장 구조는 시작 교시+기간(`period_count=2`)을 권장하며, 화면에서 둘로 펼쳐 보여주더라도 원본에는 한 묶음으로만 저장한다. 개별 교시가 독립 row로 저장되는 구현을 택한다면 DB 유니크 제약과 group 트랜잭션으로 이중 계산을 방지해야 한다.
- 수강기호는 교과와 강사 사이의 강의 식별 표기로 학기·강사에 연결한다. 과목 코드 자체와 수강기호를 혼동하지 않는다.
- **동시 편성 그룹은 synchronized_groups + synchronized_group_members로 정의**한다. 같은 과목/학기에서 한 반이 서로 다른 동시 그룹에 중복 가입하지 않도록 유효성 검사를 수행한다.
- 그룹의 고유성은 과목과 학기를 포함해 확인한다. **표시 그룹번호가 같아도 과목이 다른 경우 독립된 synchronized_group**으로 취급하며 번호로 그룹끼리 시간 충돌을 생성하지 않는다.
- 그룹 세션은 synchronized_sessions에 요일·교시·길이·잠금 정보를 한 번만 저장한다. 그룹 멤버의 timetable_entries는 synchronized_session_id를 참조해 **같은 교시를 사용**하며, 각 멤버의 teacher_id/room_id는 개별 관리한다.
- 그룹 세션 변경은 트랜잭션으로 모든 멤버 배정 항목에 반영하고, 강사 배정 시수는 실제 서로 다른 강사별 담당 교시만 계산한다.
- **주간 5교시 예외 요일 제한**은 시간표 버전/반 단위로 실제 교시 점유를 계산하고, 사전 승인된 별도 예외는 로그를 남긴다.
- 선호 교시, 일일 최대 강의 교시 수 등은 단일 구조에 고정하지 않고 확장 가능한 제약 설정으로 둔다.
- 개인정보를 최소 수집하며, OS 파일 권한·백업 관리·삭제 정책을 별도로 둔다.
- SQLite에서 PRAGMA foreign_keys=ON을 설정하고 트랜잭션을 사용한다.
- DB는 설치 폴더가 아닌 사용자별 앱 데이터 폴더에 저장한다. schema_version과 마이그레이션으로 스키마를 관리한다.

### 6.4 시간표 버전 상태

~~~text
DRAFT -> VALIDATING -> READY -> PUBLISHED -> ARCHIVED
  ^                      |
  └------ 수정 후 재검증 ┘
~~~

- DRAFT: 수동 변경·자동 생성안 적용 가능
- VALIDATING: 로컬 Python 서비스에서 전체 충돌 검사 진행
- READY: 필수 조건 충족, 게시 가능
- PUBLISHED: 조회 대상이 되는 운영본, 직접 변경 금지
- ARCHIVED: 이전 게시본 기록 보관
- 자동 편성 중 수동 수정으로 기존 배치안이 오래된 경우 revision 검사로 적용을 거절한다.
- 운영본 변경 시 새 DRAFT를 생성하여 게시 후 활성 운영본을 교체한다.

## 8. 자동 편성 엔진

### 8.1 기술 선택 — Python 설치형 프로그램

| 영역 | 선택 | 역할 |
| --- | --- | --- |
| 언어 | Python 3.12+ (호환성 확인) | 앱 전체 |
| 데스크톱 GUI | PySide6 (Qt for Python) | 창, 시간표, 대화상자 |
| 데이터 저장 | SQLite / Python sqlite3 | 오프라인 DB |
| 자동 편성 | Google OR-Tools CP-SAT | 제약 조건 최적화 |
| 계산 작업 | QThread/Worker 또는 별도 프로세스 | UI 멈춤 방지 |
| Excel | openpyxl | XLSX 출력 |
| PDF/인쇄 | PySide6 QPrinter, QPrintPreviewDialog | PDF·인쇄 |
| 배포 | PyInstaller | Windows .exe 및 macOS .app 각각 빌드·배포 |
| 테스트 | pytest, pytest-qt(선택) | 규칙·화면 테스트 |

**React, TypeScript, Node.js, FastAPI 서버, PostgreSQL, REST API를 MVP에 사용하지 않는다.** 하나의 로컬 Python 애플리케이션이 화면 → 서비스 → DB 및 최적화 엔진을 직접 호출한다.

~~~text
PySide6 GUI
   │ Python 메서드 및 Qt Signal/Slot
   ▼
Service / Validation
   ├── Repositories ── sqlite3 ── academy_timetable.db
   ├── Scheduler ── OR-Tools CP-SAT
   ├── Version / Audit / Backup
   └── Export ── PDF / XLSX / 인쇄
~~~

**로컬 저장/백업**
- DB 경로는 PySide6의 QStandardPaths.AppLocalDataLocation 등 플랫폼 표준 **사용자별 앱 데이터 디렉터리**를 사용한다(예: Windows 사용자 AppData, macOS ~/Library/Application Support 아래). 실제 경로는 앱 이름/설정에 따라 결정한다.
- 일관성 있는 백업은 sqlite3 Connection.backup()을 사용한다. 실행 중 DB 파일을 단순 복사하지 않는다.
- 복원 전에 DB 연결을 닫고 현재 데이터를 별도 백업한다.
- 동시 PC 접속용 네트워크 드라이브/클라우드 동기화 폴더에 DB 원본을 두지 않는다.

### 8.3 편성 흐름

~~~text
1. 요청 검증 및 데이터 스냅샷 생성
2. 잠금된 배정과 수업 불가 교시를 점유 상태로 적용
3. 반별 요구 시수를 실제 배치 단위(session)로 생성. 일반 과목은 연속 2교시, 영어는 1교시 묶음이며 예외는 명시적으로 허용된 경우만 사용

5. Hard Constraints로 불가능한 후보 제거
6. CP-SAT로 유효한 조합 탐색
7. Soft Constraints 점수로 후보 최적화
8. 결과 재검증 후 SQLite에 배치안(proposal) 저장
9. 관리자가 PySide6 GUI에서 수동 조정하거나 제안안을 초안에 적용
10. 최종 확정 전에 로컬 서비스가 전체 조건을 재검사
~~~

### 8.4 모델링 원칙

- 결정 변수는 각 session이 특정 시간·강사·강의실 후보에 선택되었는지 나타내는 불리언 변수로 둔다.
- 각 필수 session은 정확히 하나의 후보를 선택한다. 부분 편성 모드에서는 미배치를 명시적인 선택으로 표현한다.
- 강사·반·학생·강의실은 점유 시간 구간별 at-most-one 제약을 둔다.
- 과목 시수는 배정된 session의 교시 수 합계로 계산한다. 상위 과목/세부 과목과 병렬 선택 블록은 **학생별 실제 수강 경로를 기준으로 합산**하여 중복 계산하지 않는다.
- 같은 선택 그룹의 여러 영역은 같은 시간에 각기 다른 자원으로 병렬 배치할 수 있으며, 동일 학생이 동시에 두 그룹에 배정되지 않게 한다.
- **기본값: 영어 1교시, 그 외 정규 교과는 연속 2교시**. 각 session 후보는 시작 교시와 점유 교시 수를 함께 갖는다.
- 연속 수업은 단일 session이 여러 교시를 점유하도록 모델링한다. 전 구간에서 동일한 강사·반/학생·강의실을 점유하고 **점심(4~5), 저녁(8~9) 경계**를 넘지 못한다. 6~7교시의 20분 휴식은 기본 허용하되 교시표에서 금지 설정이 가능하다.
- 기존 고정 배정은 모델의 상수 제약으로 반영한다.
- **동시 편성 그룹**은 요일/시작 교시/교시 수를 결정하는 하나의 그룹 세션 변수를 두고, 각 반의 배정은 그 변수에 종속시킨다. 그룹 전체 잠금과 멤버별 강사·강의실 충돌을 함께 검사한다.
- **서로 다른 교과·그룹 사이에는 시간 중복 금지 제약을 따로 만들지 않는다.** 동일 교시를 선택할 수 있게 두고 실제 강사·강의실·반/학생 점유가 겹칠 때에만 at-most-one/NoOverlap 제약을 적용한다. 같은 그룹번호라도 다른 과목이면 별개 변수다.
- **오전 국수영** 후보를 기본으로 제한하고, 완전 해가 없다면 영어 5교시 후보를 포함하되 반당 주 1개 요일 이내로 제약한다. 국어·수학 5~6교시는 별도 범위 초과 승인 없이는 후보를 생성하지 않는다.
- **통합사회/통합과학**은 5~6교시만 후보로 생성하며 화·목 선호 위반량을 최소화한다. 선호로 인해 필수 배정이 실패하게 만들지 않는다.
- 불가능한 경우 원본 초안은 그대로 두고 실패 사유 또는 부분 제안만 반환한다.
- 부분 편성 모드에서는 **먼저 배정 가능한 필수 시수의 최대화, 그다음 선호 최적화** 순서의 우선순위(사전식 최적화)를 사용한다.
- 최적화 시간 제한과 중단 정책은 실제 학원 규모를 측정한 후 결정한다.

### 8.5 실패 이유 안내

예시:

> 수학 1교시 미배치: 담당 가능 강사의 남은 근무 시간에 수용 가능한 강의실이 존재하지 않습니다.

실패 진단은 확정적인 전체 불가능 원인 증명과 간단한 후보 필터 분석을 구분해야 한다. 복잡한 모델에서는 여러 제약이 복합적으로 충돌할 수 있으므로 원인을 단정하지 않는다. 관리자에게 강사 가능 시간 조정, 강의실 변경, 고정 교시 해제 검토 등의 해결 후보를 보여준다.

### 9.4 오류 처리

HTTP 오류 코드 대신 Python 예외 및 결과 타입을 사용한다. 예: ValidationError, ScheduleConflictError, StaleRevisionError, SolverInfeasibleError, StorageError, BackupError. 사용자는 한국어 오류 대화상자와 관련 반/강사/교시 및 해결 후보를 확인한다.

## 10. 시간표 검증 및 게시 정책

1. 편집 중에는 오류를 즉시 표시할 수 있으나 유효하지 않은 제안 상태는 운영본에 반영되지 않는다.
2. 로컬 Python 서비스 계층은 기본 무결성 및 자원 중복을 검사한다.
3. 자동 편성 결과를 **원본이 아닌 제안안**으로 저장한다.
4. 제안안 적용 때 입력 시점의 revision과 현재 revision이 같은지 확인한다.
5. '시간표 확정' 기능은 전체 Hard Constraints, 필수 시수, 적용 기간을 재검증한다.
6. 통과한 경우 단일 트랜잭션으로 기존 운영본을 보관하고 새 버전을 PUBLISHED로 만든다.
7. 게시본 직접 편집을 차단하고 변경이 필요하면 새 DRAFT를 생성한다.
8. 모든 주요 변경과 게시 이력은 audit_logs에 남긴다.

자동 편성 도중 수동 편집이 이루어졌다면 revision 검사를 통해 이전 계산 결과가 최신 초안을 덮어쓰지 못하도록 한다. HTTP/ETag는 사용하지 않는다.

## 11. 날짜별 예외와 자습

- **정규 반복 시간표**: 요일·교시별 기본 수업. term 기간 내 매주 반복.
- **특정 날짜 예외**: EXAM, CANCEL, SUBSTITUTE, MAKEUP, MOVE 등.
- **조회 규칙**: 특정 날짜의 시간표를 요청하면 정규 시간표를 복제한 가상 결과에 예외를 적용한다.
- **검증 규칙**: 보강·대체 수업도 강사/학생/강의실 자원 중복 검사 대상이다.
- **자습**: 별도 활동 유형이며 강의실 또는 자습실, 감독 강사 필요 여부를 설정한다.

선택수업은 반 전체 시간표에 단일 과목이 아니라 "선택수업 블록"으로 보여줄 수 있으며, 학생·선택그룹별 세부 시간표에서는 실제 선택 과목과 강의실을 표시한다.

## 12. 출력 및 조회 — Excel(.xlsx) 정식 지원

**Excel 출력은 MVP의 필수 기능이다.** 화면을 캡처한 이미지가 아니라 **Excel에서 직접 수정할 수 있는 일반 셀 기반의 .xlsx 파일**로 내보낸다. PDF와 프린터 출력은 별도로 유지한다.

### 12.1 내보내기 대상 및 선택 옵션

| 강사별 시간표 | 선택 강사 또는 모든 강사 각각 시트 | 요일×교시, 반, 과목, 강의실 |
| 강의실별 시간표 | 선택 강의실 또는 모든 강의실 각각 시트 | 요일×교시, 반, 강사, 과목 |
| 전체 배정 목록 | 전체_배정목록 시트 | 학기, 요일, 교시, 시간, 반, 과목, 강사, 강의실, 수업 유형, 잠금 |

### 12.2 Excel 파일 기능 요구사항

- Python openpyxl로 Workbook을 생성하고 .xlsx로 저장한다. 사용 PC에 Microsoft Excel이 설치되어 있지 않아도 생성할 수 있어야 한다.
- 엑셀 파일은 텍스트를 포함하는 **편집 가능한 셀**로 만든다. 과목, 담당 강사, 강의실은 줄바꿈으로 표시할 수 있다.
- 교시·시간을 행 헤더, 운영 요일(월~토 등)을 열 헤더로 작성한다.
- 과목별 색상, 제목 강조, 테두리, 셀 가운데 정렬, 자동 줄바꿈, 열 너비/행 높이, 헤더 행 고정을 적용한다.
- 연속 교시 수업은 필요한 경우 세로 셀 병합으로 표시하되, 병합 전 다른 배정이 덮이지 않는지 확인한다. **2교시 묶음은 인쇄 시 2교시 점유를 명확히 표현**하고 영어는 1교시만 표시한다.
- 인쇄 설정은 기본 A4 가로, 인쇄 영역 지정, 한 페이지 너비 맞춤, 상단 제목/헤더 반복, 여백 설정으로 한다.
- 워크시트 이름의 31자 제한, 금지 문자, 중복 시트명 문제를 자동 처리한다.
- UTF-8 기반 한국어 텍스트를 유니코드 셀 값으로 저장하여 한글이 정상 표시되도록 한다.
- 저장 대상 파일이 존재하면 덮어쓰기 확인, 파일 사용 중 또는 권한 부족이면 오류 안내, 원본 시간표 유지.
- 출력에 불필요한 학생 연락처/개인정보를 넣지 않는다.
- **Excel을 수정해도 SQLite 원본 시간표가 자동 변경되지는 않는다.** Excel 가져오기(import)는 후속 기능으로 분리한다.

### 12.5 기능 검증 및 테스트

1. 특정 반/강사/강의실을 선택하면 정확한 대상 시트만 생성된다.
2. 전체 내보내기에서는 모든 대상별 시트와 전체 배정 목록/시수 요약이 생성된다.
3. 생성된 xlsx를 openpyxl.load_workbook으로 다시 열었을 때 모든 시트/셀 정보가 일치한다.
4. 과목 색상, 셀 병합, 헤더 고정, A4 가로, 인쇄 영역이 설정된다.
5. 한글 텍스트, 31자 이상의 이름, 같은 이름을 가진 시트, 금지 문자가 안전하게 처리된다.
6. 파일의 수업 셀을 수정해 다시 저장할 수 있다.
7. 엑셀 출력이 원본 SQLite DB를 수정하지 않는다.
8. 파일 잠김/권한 부족/덮어쓰기 취소 등 실패 상황을 사용자에게 설명한다.
9. 초안 표기, 적용 기간, 출력일 등 메타데이터가 정확하다.
10. 개인정보와 내부 감사 정보가 선택하지 않은 출력물에 포함되지 않는다.
11. 화작·언매 등 세부 영역이 서로 다른 시트/배정 목록에서 구분되고 각 학생의 수강 시수가 이중 계산되지 않는다.
12. 동시 편성 그룹 B/C는 Excel의 같은 요일·교시에 함께 표시되고 강사·강의실 정보는 각 반별로 구분된다.
13. 통합사회·통합과학은 5~6교시 2T로 표현되며 화·목 우선 결과 및 국수영 5교시 예외를 검토 시트에 표시할 수 있다.

### 12.5.1 강사 배정 시수 Excel 레이아웃

- 첨부 표처럼 **교과명 / 강사명 / 수강기호**는 좌측, 상단 **배정시수** 아래 세부 과목별 열, 우측 **합계**, 하단 **전체 합계**를 두는 매트릭스 형태로 만든다.
- `openpyxl`의 셀 병합으로 교과 그룹 헤더/배정시수 상위 헤더를 표시하고, 과목별 시수는 편집 가능한 숫자 셀로 내보낸다.
- 강사별 행/과목별 열/총합 숫자의 일치를 검사한다. 행 그룹, 테두리, 가운데 정렬, 색상, 인쇄 영역 설정을 반영한다.
- 과목이 늘면 열을 동적으로 확장하며 A3 가로를 우선 사용하고, 사용자가 A4/여러 페이지로 조정할 수 있게 한다.
- 시트는 내보낼 때의 시간표 버전과 과목 분류에 대한 **스냅샷**이다. Excel에서 숫자를 수정해도 SQLite의 실제 강사 시수는 자동 변경되지 않는다.

| 구분 | Windows | macOS |
| --- | --- | --- |

| 배포 산출물 | .exe 또는 설치 프로그램 | .app, 선택적으로 .dmg |

- 개발 환경에서는 각 플랫폼의 가상환경에서 Python 모듈로 실행하고, 일반 사용자에게는 Python/터미널 설치를 요구하지 않는 앱 배포를 목표로 한다.
- **PyInstaller는 운영체제별 네이티브 빌드가 필요하다.** Windows .exe는 Windows에서, macOS .app은 macOS에서 각각 빌드·검증한다. macOS Intel 및 Apple Silicon 아키텍처별 의존성 휠 호환성과 필요 시 아키텍처별 앱 빌드를 검토한다.
- macOS 배포 시 Gatekeeper 경고를 줄이기 위한 Apple Developer ID 코드 서명과 공증(notarization), 필요 시 .dmg 포장을 배포 단계에서 검토한다. 테스트용 앱과 외부 배포용 앱의 요구사항을 구분한다.
- Windows 서명은 외부 배포 시 신뢰도 확보를 위한 선택 사항으로 검토한다.
- 처음 실행 시 로컬 데이터베이스/설정 폴더를 생성하고 마이그레이션한다. 시스템 설치 디렉터리나 .app 패키지 내부에 사용자 DB를 저장하지 않는다.
- 프로그램 내부에 운영체제별 절대 경로, 슬래시, 글꼴 경로, EXE 확장자를 하드코딩하지 않고 pathlib 및 Qt 플랫폼 API를 사용한다.
- 오프라인 동작을 유지한다. 인터넷 연결은 핵심 시간표 편성·저장·XLSX/PDF 출력에 필요하지 않다.

### 13.2 OS별 GUI와 파일 처리 설계

- PySide6의 `QKeySequence.StandardKey`를 사용하여 저장·복사·붙여넣기·실행 취소 등 표준 단축키가 Windows에서는 Ctrl, macOS에서는 Command(⌘)로 자연스럽게 동작하도록 한다.
- Qt 네이티브 파일 대화상자(`QFileDialog`)로 열기·저장·엑셀 출력·백업 경로를 선택한다. macOS에서는 Finder 스타일 파일 선택창을 사용한다.
- 플랫폼별 메뉴바 배치(Windows 앱 창 / macOS 시스템 메뉴바)와 종료/설정 메뉴 차이를 Qt 표준 방식으로 처리한다.
- Windows DPI 배율과 macOS Retina 배율, 라이트/다크 모드, 시스템 폰트/한글 표시를 GUI 테스트에 포함한다.
- 로컬 저장 경로는 QStandardPaths로 얻고, Path 객체로 조작한다. 백업 파일은 사용자가 선택한 경로에 저장한다.
- SQLite DB 및 설정·로그는 각 OS 사용자별 앱 데이터 디렉터리에 분리 저장한다. OS별 경로가 달라도 데이터 스키마와 백업 파일 포맷은 동일하게 유지한다.
- Windows에서 생성한 백업 DB를 macOS에서 복원하거나 반대로 복원할 때 동일 앱 스키마 버전이라면 데이터가 유지되도록 설계하고 교차 복원 테스트를 실시한다.
- XLSX 및 PDF 파일은 두 OS에서 **동일한 시트·셀 값과 출력 구조**가 생성되어야 한다. 시스템 글꼴 차이로 발생하는 인쇄 레이아웃 차이는 실제 PDF/인쇄 테스트로 확인한다.

### 14.1 핵심 테스트 케이스

1. **강사 중복**: A반과 B반이 동일 교시에 같은 강사를 사용하면 거절된다.
2. **강의실 중복**: 서로 다른 반에서 같은 공간을 같은 시간에 쓰면 거절된다.
3. **학생 중복**: 선택수업 학생이 정규반 수업과 겹치면 거절된다.
4. **고정 보호**: 자동 재배치 후 잠금된 entry의 시간·강사·강의실이 유지된다.
5. **시수 보존**: 과목별 required_periods_per_week와 실제 배정 교시 수가 일치한다.
6. **연속 교시**: 두 교시 수업이 허용 슬롯을 모두 점유하며 중복되지 않는다.
7. **부분 편성**: 완전 해가 없어도 기존 초안 보존, 미배치 목록과 원인 표시.
8. **낙관적 잠금**: 오래된 revision 기반 배치안 적용은 StaleRevisionError로 거절한다.
9. **게시 원자성**: 게시 실패 시 기존 PUBLISHED 버전은 그대로 유지된다.
10. **날짜별 예외**: 하루만 휴강해도 다른 주 반복 시간표는 변경되지 않는다.
11. **로컬 데이터 접근**: SQLite가 OS 사용자별 데이터 폴더에 생성되고 파일 접근 권한이 적용된다.
12. **시간 충돌 경계**: 한 수업의 종료와 다른 수업의 시작이 같으면 겹치지 않는다.
13. **GUI 응답성**: 자동 편성 중에도 창이 멈추지 않고 완료/취소/실패 상태가 표시된다.
14. **백업·복원**: 일관성 있는 DB 백업을 만들고 복원 이전 원본을 보존한다.
15. **오프라인**: 인터넷 없이 등록·수동/자동 편성·출력이 작동한다.
16. **엑셀 출력**: 모든 반·강사·강의실별 편집 가능한 .xlsx와 인쇄 설정을 검증한다.
16-1. **세부 과목 구분**: 국어 공통/화작/언매가 GUI·시간표·XLSX에서 별도 표시된다.
16-2. **선택 규칙**: 택1 그룹에 두 과목을 동시에 선택하면 검증에서 발견된다.
16-3. **시수 계산**: 상위 국어 시수와 하위 영역 시수가 중복 계산되지 않는다.
16-4. **병렬 선택수업**: 같은 교시의 화작·언매는 다른 강사·강의실과 비중복 학생이면 가능하다.
16-5. **강사 배정 시수표**: 교과별 그룹·강사명·수강기호·과목별 열·행/열/총계가 화면 및 XLSX에서 일치한다.
16-6. **시수 자동 갱신**: 수동/자동 배정 수정 및 버전 변경 후 강사 시수가 자동 업데이트되고 중복 계산이 없다.
16-7. **기본 수업 길이**: 국어/수학/탐구의 자동 생성은 2교시 연속 묶음, 영어는 1교시 단독으로 생성된다.
16-8. **연강 무결성**: 연강 교시 중 하나만 이동/삭제할 수 없고, 교차 점심·강사/교실 변경을 검출한다.
16-9. **홀수 시수**: 일반 과목 주 5교시는 예외가 없으면 사전 오류, 승인된 1교시 잔여 예외가 있으면 유효하게 처리된다.
16-10. **집계 검증**: 연강 2교시는 강사 시수표·과목 시수·Excel 합계에 정확히 2로 반영된다.
16-11. **기본 교시표**: 1~11교시의 시작·종료 시간이 사용자 제공 시각과 정확히 일치한다.
16-12. **연강 경계**: 4~5교시/8~9교시 연강을 차단하고 6~7교시 20분 휴식 경계는 설정에 따라 허용한다.
16-13. **출력 정합성**: 11교시 및 점심·저녁 구분이 GUI와 최종 Excel/PDF에 동일하게 표시된다.
16-14. **동시 그룹 기본 예시**: 국어 문학 2그룹 B·C는 월요일 1~2교시에 각각 다른 강사/실로 동시 배정되며, 한 반만 이동하려고 하면 차단된다.
16-15. **국수영 오전 배치**: 월~금 1~4교시에 우선 배치하고 영어 5교시 예외는 반당 한 요일 이내만 허용한다.
16-16. **연강 범위 모순 처리**: 국어·수학을 승인 없이 4~5/5~6교시로 배치하지 않고 사유를 보여준다.
16-17. **통합사회·과학**: 각각 5~6교시 2교시 연강만 허용하고, 화·목이 부족하면 다른 평일 5~6교시로 배치한다.
16-18. **그룹 검증/시수**: 그룹 반별 요구 시수 일치, 실제 개별 강사의 시수만 카운트, 동일 강사·강의실 중복 검출.
16-19. **교과 간 병렬 편성**: 국어 2그룹 B·C와 수학 2그룹 D·E가 월 1~2교시에 함께 있어도 자원 충돌 0건이면 허용된다.
16-20. **실제 자원 충돌**: 다른 교과라도 강사/실 또는 동일 반 전체/학생이 겹치면 오류로 검출된다.
16-21. **그룹번호 독립성**: 국어 2그룹 이동·잠금은 수학 2그룹에 영향을 주지 않는다.
17. **Windows/macOS 동등 기능**: 두 OS에서 GUI 편집, 수동/자동 편성, Excel/PDF 출력, 백업/복원 결과가 일치한다.
18. **OS별 실행 파일**: Windows .exe와 macOS .app을 각각 실행해 터미널 없이 창이 열리는지 확인한다.
19. **데이터 이식성**: Windows에서 백업한 SQLite를 macOS에서 복원하고 반대 방향도 테스트한다.
20. **단축키·고해상도**: Ctrl/Command 표준 단축키, Windows 배율, macOS Retina 및 한글 UI를 확인한다.

- 국어·수학이 오전에 배치 불가능할 때 5~6교시 2T까지 허용할지 여부(기본 비허용, 별도 승인 필요)
- 과목별 필수 시수와 반별 편차
- 한 교시에 여러 과목을 병행하는 이동수업의 세부 운영
- 자습실/감독 강사 배치 기준
- 강사별 일일 최대 강의 및 연속 강의 제한
- 인쇄·파일 공유 외 별도 학생/학부모 조회 도구의 도입 여부
- 인쇄 레이아웃 및 파일 양식
- 자동 편성 성능 목표를 검증할 샘플 데이터 규모
- Windows/macOS의 최소 지원 버전 및 macOS Intel/Apple Silicon 별 빌드 범위 확정
