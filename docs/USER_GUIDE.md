## 1. 다운로드와 실행

GPT·GitHub 계정이나 로그인 없이 사용할 수 있습니다. **Python이 설치되지 않은 컴퓨터에서도 실행할 수 있도록 Python 실행 환경과 필요한 라이브러리가 파일에 포함되어 있습니다.**

| 운영체제 | 다운로드 | 실행 순서 |
| --- | --- | --- |
| Windows 10 1809 이상 x64 · Windows 11 | [AcademyTimetable-Setup.exe](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable-Setup.exe) | 파일을 내려받아 더블클릭하고 **설치 → 완료**를 누릅니다. |
| Apple Silicon Mac | [AcademyTimetable-macOS-arm64.zip](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable-macOS-arm64.zip) | 압축을 푼 뒤 `학원 시간표.app`을 더블클릭합니다. |

### Windows 설치 순서

1. 위의 **AcademyTimetable-Setup.exe** 링크에서 설치 파일을 내려받습니다. 파일 이름의 확장자가 `.exe`인지 확인합니다.
2. 다운로드가 끝난 파일을 더블클릭하고 **설치**를 누릅니다. 현재 사용자 폴더에 설치되므로 관리자 계정의 비밀번호를 요구하지 않습니다.
3. 완료 화면에서 **학원 시간표 실행**을 체크한 상태로 **완료**를 누르면 프로그램이 열립니다.
4. 다음부터는 바탕화면이나 시작 메뉴의 **학원 시간표**를 더블클릭합니다. 설치 파일을 매번 실행할 필요는 없습니다.

Windows 지원 기준은 **Windows 10 버전 1809(빌드 17763) 이상 64비트와 Windows 11 x64**입니다. 이는 사용하는 [Qt의 지원 조건](https://doc.qt.io/qt-6/supported-platforms.html)에 따른 것으로 Windows 10 초기 버전과 32비트 Windows는 지원하지 않습니다. `Win + R → winver`로 버전을 확인하고, Windows 설정의 시스템 정보에서 64비트 여부를 확인하세요.

설치 없이 사용하려면 [AcademyTimetable.exe](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable.exe)를 내려받아 실행할 수도 있습니다. 이 파일에도 Python 실행 환경이 포함됩니다.

실행 파일은 개발 확인용이며 Windows 배포 서명과 macOS 공증은 제공하지 않습니다. **인식할 수 없는 앱**, **게시자를 확인할 수 없음** 등 Windows 경고는 앱의 서명·평판 확인에 관한 것으로 GPT 로그인이나 Python 설치를 요구하는 화면과 구분해야 합니다. 보안 경고가 표시되면 파일의 다운로드 출처를 확인하세요. [Microsoft의 SmartScreen 안내](https://learn.microsoft.com/en-us/windows/security/operating-system-security/virus-and-threat-protection/microsoft-defender-smartscreen/)에서 경고의 의미를 확인할 수 있습니다.

다운로드한 뒤에는 인터넷 연결 없이 사용할 수 있습니다. 학원 데이터는 실행 파일과 별도로 컴퓨터의 사용자별 앱 데이터 폴더에 저장됩니다.

## 2. 처음 수업 하나 만들기

처음에는 아래 예시로 **A반의 월요일 1·2교시 수학 수업**을 만들어 보세요. 예시에 나오는 이름과 인원은 설명을 위한 가상 값입니다.

1. 왼쪽 **학기 관리 → + 추가**에서 `예시 학기`를 만듭니다. 오른쪽 위 **학기**에서 이 학기를 선택합니다.
2. **반 관리 → + 추가**에서 `A반`을 만들고, 반을 선택한 뒤 **인원 설정**에 `25`를 입력합니다.
3. **강사 관리**에 `김강사`, **과목 관리**에 `수학`, **강의실 관리**에 `101호`를 추가합니다. 101호의 **정원 설정**에는 `30`을 입력합니다.
4. **과목 관리**에서 수학을 선택하고 **담당 강사 설정**에 김강사를 체크해 **저장**합니다.
5. **강사 가능 시간**에서 김강사를 고릅니다. 월요일 1·2교시를 선택한 뒤 **가능**을 누릅니다.
6. **시간표 편집**에서 A반을 선택하고 **시수 설정**을 누릅니다. 과목은 수학, **주간 목표 교시**는 `2`, **1회 수업 길이**는 `2교시 연강`으로 저장합니다.
7. 월요일 1교시를 더블클릭합니다. 수학과 김강사를 고르고 강의실은 **미배정**으로 둔 채 저장합니다. 월요일 1·2교시가 함께 채워집니다.
8. **강의실 배정 → 자동 제안**에서 101호가 제안되는지 확인하고 **제안 적용**을 누릅니다.
9. **초안 검토**에서 결과를 확인합니다. **강사 시수 관리**에서는 김강사의 수학이 `2`시수로 집계됩니다.
10. 상단 **엑셀 내보내기**에서 결과를 파일로 저장합니다.

예시처럼 반을 하나만 등록하면 초안 검토의 **반 수**에 확인 필요가 표시될 수 있습니다. 해당 검토 항목은 3~10개 반을 운영 기준으로 확인합니다.

## 3. 화면 구성과 저장 방식

| 위치 | 용도 |
| --- | --- |
| 오른쪽 위 **학기** | 반, 교시표, 시간표, 강사 가능 시간, 검토 및 엑셀 출력의 대상 학기를 선택합니다. |
| 왼쪽 메뉴 | 기본 정보, 시간표 편집, 강사 시수, 강의실 배정, 백업 화면으로 이동합니다. |
| 상단 **엑셀 가져오기** | 이름 목록을 가져오거나 엑셀에 작성된 시간표를 불러옵니다. |
| 상단 **엑셀 내보내기** | 선택 학기의 시간표 초안을 `.xlsx`로 저장합니다. |
| 오른쪽 위 **사용 방법** | 프로그램 안에서 기능별 사용 안내를 읽습니다. |

반과 반 인원은 학기별로 관리합니다. 강사·과목·강의실 목록과 과목별 담당 강사 설정은 여러 학기에서 함께 사용합니다.

각 대화상자의 **저장**, **시간표에 추가**, **제안 적용** 등을 누르면 해당 내용이 저장됩니다. 강사 가능 시간은 **가능·불가·미설정**을 누를 때 바로 저장됩니다. **교시·시간 설정**은 수정 후 반드시 **교시표 저장**을 눌러야 합니다.

## 4. 학기와 기본 정보 관리

### 학기와 교시

1. **학기 관리 → + 추가**에서 학기를 등록합니다. 새 학기에는 기본 11교시가 생성됩니다.
2. 오른쪽 위 **학기**에서 작업할 학기를 선택합니다.
3. **교시·시간 설정**에서 시작·종료 시각을 `08:30`처럼 24시간 형식으로 입력합니다.
4. **교시표 저장**을 누릅니다. 각 교시는 시작이 종료보다 앞서야 하며 다른 교시와 겹칠 수 없습니다.

시간표는 **월요일~토요일, 1~11교시**를 사용하며 교시 시각은 해당 학기의 모든 요일에 공통으로 적용됩니다. 수정한 교시표는 학기를 바꾸거나 앱을 종료하기 전에 저장하세요.

### 반·강사·과목·강의실

- 각 관리 화면에서 **+ 추가**로 이름을 등록합니다. 항목을 선택하고 **이름 수정**으로 바꿀 수 있습니다.
- **반 관리 → 인원 설정**에는 반 인원을, **강의실 관리 → 정원 설정**에는 강의실 정원을 입력합니다. `0`을 입력하면 미설정으로 저장됩니다.
- 과목은 **활성/비활성**으로 관리합니다. 비활성 과목의 기록은 유지되며 새 수업을 배정하려면 활성화해야 합니다.
- 수업에서 사용 중인 반·강사·강의실은 삭제가 제한될 수 있습니다.
- 학기 삭제는 해당 학기의 반·교시표·강사 가능 시간에도 적용됩니다. 시수나 수업이 있는 학기는 먼저 연결된 내용을 정리해야 합니다. 삭제 전에 백업하세요.

## 5. 담당 강사와 가능 시간

### 과목별 담당 강사 설정

1. **과목 관리**에서 과목을 선택하고 **담당 강사 설정**을 누릅니다.
2. 해당 과목을 맡을 강사를 체크하고 **저장**합니다.
3. 이후 수업 편집에서 해당 강사들이 후보로 표시됩니다. 이 설정은 모든 학기에 적용됩니다.

모든 체크를 해제하면 등록된 강사 중에서 수동 배정할 수 있습니다. 설정을 바꿔 기존 수업의 강사가 조건과 맞지 않게 되면 **초안 검토**에서 확인할 수 있습니다.

### 학기별 가능 시간 설정

1. 오른쪽 위 학기를 확인하고 **강사 가능 시간**으로 이동합니다.
2. 강사를 고른 뒤 교시를 하나 또는 여러 개 선택합니다.
3. **가능**, **불가**, **미설정** 중 하나를 누릅니다. 선택한 교시에 즉시 저장됩니다.

| 상태 | 의미와 처리 |
| --- | --- |
| 가능 | 해당 교시에 수업할 수 있는 것으로 확인한 상태입니다. |
| 불가 | 해당 교시에 수업을 배정할 수 없습니다. 이미 수업이 있다면 먼저 이동하거나 삭제해야 합니다. |
| 미설정 | 가능 여부를 아직 확인하지 않은 상태입니다. 수동 배정은 가능하며 초안 검토에서 확인 필요로 표시됩니다. |

## 6. 주간 시수와 시간표 편집

### 반별 과목 시수 등록

1. **시간표 편집** 위쪽의 **반**에서 작업할 반을 고릅니다.
2. **시수 설정**에서 과목, **주간 목표 교시**, **1회 수업 길이**를 저장합니다.
3. 시수표의 **배정 / 잔여**를 보며 필요한 수업을 채웁니다.

이 프로그램에서 시수는 교시 수입니다. `주간 목표 4교시 + 2교시 연강`이면 연강을 두 번 배정합니다. 목표 교시는 수업 길이로 나누어떨어져야 하므로 `목표 3교시 + 2교시 연강`으로는 저장할 수 없습니다.

시수 설정을 삭제하려면 해당 과목에 배정된 수업을 먼저 삭제해야 합니다.

### 수업 배정과 수정

1. 원하는 요일·교시를 더블클릭하거나 선택한 뒤 **배정 / 수정**을 누릅니다.
2. 과목과 강사, 요일과 시작 교시를 확인합니다. 강의실은 선택하거나 **미배정**으로 둘 수 있습니다.
3. 저장하면 설정한 수업 길이만큼 시간표에 표시됩니다.
4. 기존 수업을 바꾸려면 해당 수업을 선택하고 **배정 / 수정**을 누릅니다. 강사·강의실·요일·시작 교시를 변경할 수 있습니다.

과목을 바꾸려면 기존 수업을 삭제하고 새로 배정합니다. 반·강사·강의실의 시간 중복이나 목표 시수 초과가 있으면 저장이 차단되고 이유가 표시됩니다.

### 연강·잠금·삭제

- 2교시 연강은 두 칸에 표시되며 함께 이동·삭제됩니다.
- 4~5교시와 8~9교시 경계를 가로지르는 연강, 11교시를 넘는 연강은 저장할 수 없습니다.
- 수업을 선택하고 **잠금 / 해제**를 누르면 변경을 막거나 다시 허용할 수 있습니다.
- 잠긴 수업을 수정·이동·삭제하거나 강의실을 바꾸려면 먼저 잠금을 해제합니다.
- 수업을 지우려면 해당 수업을 선택하고 **수업 삭제**를 누릅니다.

## 7. 강의실 배정과 자동 제안

### 인원과 시설 준비

1. **반 관리 → 인원 설정**에 반 인원을 입력합니다.
2. **강의실 관리 → 정원 설정**에 각 강의실의 정원을 입력합니다.
3. 시설이 필요한 과목은 **과목 관리 → 시설 설정**에 필수 시설을 적습니다.
4. **강의실 관리 → 시설 설정**에는 보유 시설을 적습니다. 여러 시설은 줄바꿈이나 쉼표로 구분하며 양쪽에서 같은 이름을 사용합니다.

반 인원보다 정원이 작거나 필수 시설이 부족한 강의실은 배정할 수 없습니다. 수동 배정은 인원·정원 중 한 값이 미설정이어도 가능하며, 초안 검토에 확인 필요로 표시됩니다.

### 수동으로 강의실 배정

1. **강의실 배정**에서 수업을 선택합니다.
2. **빈 강의실**에서 수업 전체 교시에 비어 있고 조건에 맞는 강의실을 고릅니다.
3. **강의실 저장**을 누릅니다. 배정을 비우려면 **미배정**을 선택해 저장합니다.

### 여러 수업의 강의실 자동 제안

1. **자동 제안**을 눌러 미배정 수업의 제안 강의실과 미배정 사유를 확인합니다.
2. 내용을 검토한 뒤 **제안 적용**을 누릅니다.
3. 남은 미배정 수업은 인원·정원·시설과 빈 시간을 확인하고 직접 배정하거나 다시 제안받습니다.

자동 제안은 **이미 저장된 수업의 강의실**을 찾는 기능이며 수업 시간과 강사는 유지됩니다. 반 인원이 미설정이거나 잠긴 수업은 건너뛰고, 정원이 미설정인 강의실은 후보에서 제외됩니다. 제안 적용 시 조건을 다시 확인하며, 다른 창에서 내용이 변경됐다면 새로고침 후 다시 제안받으세요.

## 8. 초안 검토와 강사 시수 확인

1. **초안 검토**를 열고 대상 학기를 확인합니다.
2. **다시 검토**를 눌러 현재 저장된 내용으로 결과를 갱신합니다.
3. 상세 칸의 반·과목·강사·요일·교시를 보고 해당 관리 화면에서 수정합니다.
4. 수정한 뒤 **다시 검토**를 눌러 결과를 비교합니다.

| 표시 | 확인할 내용 |
| --- | --- |
| 오류 | 시간 중복, 담당 강사 불일치, 강사 불가 시간, 정원·필수 시설 부족 등을 수정합니다. |
| 확인 필요 | 잔여 시수, 강의실 미배정, 강사 가능 시간 미설정, 인원·정원 미설정 등을 확인합니다. |

초안 검토는 읽기 전용입니다. 결과가 없더라도 아직 구현되지 않은 운영 규칙까지 검증됐다는 뜻은 아닙니다.

**강사 시수 관리**에서는 선택 학기의 강사별·과목별 실제 배정 교시를 확인합니다. 2교시 연강 한 번은 2시수로 집계됩니다. 반별 목표와 잔여 교시는 **시간표 편집**에서 확인하세요.

## 9. 엑셀 가져오기

### 이름 목록 가져오기

반·강사·과목·강의실의 이름을 한 번에 등록할 때 사용합니다.

1. 첫 행에 열 제목이 있는 `.xlsx` 파일을 준비합니다. 이름은 텍스트로 입력합니다.
2. 반을 등록할 학기를 오른쪽 위에서 선택합니다.
3. **엑셀 가져오기 → 기본 정보 가져오기**에서 파일과 시트를 고릅니다.
4. 반·강사·과목·강의실에 각각 해당하는 원본 열을 지정합니다. 가져올 항목만 연결하면 됩니다.
5. **미리보기**에서 원본 값과 행별 확인 결과를 살펴봅니다. 잘못 연결한 열을 수정하고, 원본 값의 오류는 엑셀에서 고친 뒤 다시 불러옵니다.
6. 오류가 없어지면 **가져오기**를 누릅니다.

같은 이름은 기존 항목을 사용합니다. 이 화면에서는 이름을 등록하며 교과·레벨·수강기호·시수 열은 미리보기에서만 확인할 수 있습니다. 원본 엑셀 파일은 변경하지 않습니다.

### 엑셀의 시간표 불러오기

1. 수업을 추가할 **학기**를 먼저 선택합니다. 기존 학기와 구분해 확인하려면 새 학기를 만들어 선택하세요.
2. **엑셀 가져오기 → 시간표 불러오기 → 엑셀 파일 선택**에서 `.xlsx` 파일을 엽니다.
3. 시트 목록에서 실제 시간표가 있는 **시트 하나를 직접 선택**합니다. 시트가 여러 개라면 필요한 시트마다 같은 절차를 반복합니다.
4. 앱에서 내보낸 파일은 **전체_배정목록** 시트를 선택합니다. 요일·반이 가로로 있고 과목과 강사기호가 두 행씩 짝을 이루는 지원 형식의 격자도 읽을 수 있습니다.
5. **미리보기**를 눌러 엑셀 위치와 **추가·건너뜀·오류**를 확인합니다.
6. 오류를 해결한 뒤 **시간표에 추가**를 누릅니다. 완료 후 **시간표 편집**에서 반별 결과를 확인합니다.

파일에만 있는 반·과목·강사·강의실은 새로 등록됩니다. 시수 설정이 없는 반·과목은 불러온 교시 합계로 목표 시수를 만듭니다. 기존 수업·시수 설정·교시 시각은 유지되고 같은 수업은 건너뜁니다. 격자 시간표는 각 교시를 별도 수업으로 저장하며, 강사기호로 작성된 값은 그 문자열이 강사 이름으로 사용됩니다.

### 직접 작성하는 배정 목록 형식

첫 행에 아래 열 제목을 적고 **수업 한 건을 한 행**에 입력하면 됩니다.

| 반 | 과목 | 강사 | 강의실 | 요일 | 시작 교시 | 종료 교시 | 시수 | 잠금 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A반 | 수학 | 김강사 | 101호 | 월 | 1 | 2 | 2 | 해제 |
| B반 | 영어 | 이강사 |  | 토 | 3 |  | 1 | 해제 |

- **필수 열**은 `반`, `과목`, `강사`, `요일`, `시작 교시`입니다. 반·과목·강사 이름은 텍스트로 입력합니다.
- 요일은 `월`~`토` 또는 `월요일`~`토요일`, 교시는 `1`~`11`을 사용합니다.
- `종료 교시`와 `시수`는 선택입니다. 둘 다 비우면 1교시 수업으로 처리합니다. 시수는 `1` 또는 `2`이며, 두 값을 모두 입력했다면 서로 일치해야 합니다.
- `강의실`을 비우면 미배정으로 저장합니다. `잠금`은 `잠금` 또는 `해제`이며, 비우면 해제 상태입니다.
- 수식이나 엑셀 오류 값은 가져올 수 없습니다. 값을 텍스트나 숫자로 확정한 뒤 다시 불러오세요.

불러오기는 현재 학기에 수업을 추가하는 방식입니다. 엑셀에서 바꾼 기존 수업을 자동으로 덮어쓰지 않으므로, 기존 수업의 시간·강사를 고칠 때는 **시간표 편집**에서 수정하세요.

## 10. 엑셀 내보내기

1. 오른쪽 위에서 출력할 학기를 선택합니다.
2. 수정 중인 교시표가 있다면 **교시표 저장**을 누릅니다.
3. 상단 **엑셀 내보내기**를 누르고 저장할 위치와 파일 이름을 고릅니다.
4. 저장된 `.xlsx` 파일을 엑셀 등에서 엽니다.

파일에는 반별·강사별·강의실별 시간표, **전체_배정목록**, 반별 과목 시수 요약, 강사 배정 시수가 포함됩니다. 2교시 연강은 두 교시에 표시되며 강의실 미배정 수업도 표시됩니다.

엑셀 파일을 수정해도 프로그램에는 자동 반영되지 않습니다. 프로그램에서 시간표를 수정한 뒤 다시 내보내면 최신 결과를 받을 수 있습니다.

## 11. 백업과 복원

### 백업 저장

1. 편집 중인 교시표 등 저장하지 않은 내용을 먼저 저장합니다.
2. **백업·복원 → 백업 파일 저장**을 누릅니다.
3. 보관할 위치와 이름을 선택해 `.sqlite3` 파일을 저장합니다. 날짜가 포함된 이름을 사용하면 구분하기 쉽습니다.

백업 파일에는 저장된 **모든 학기, 시간표와 설정**이 포함됩니다. 강사와 학원 운영 정보가 들어 있으므로 안전한 위치에 보관하세요.

### 백업에서 복원

1. 다른 프로그램 창의 변경 사항을 저장하고 창을 닫습니다.
2. **백업·복원 → 백업 파일에서 복원**에서 `.sqlite3` 파일을 선택합니다.
3. 확인 메시지에서 교체 범위를 읽고 진행합니다.
4. 복원 후 앱을 다시 실행해 학기와 시간표를 확인합니다.

**복원하면 현재의 모든 학기와 시간표가 백업의 내용으로 교체됩니다.** 복원 직전 데이터는 앱 데이터 폴더에 `before_restore_...sqlite3`로 자동 보관되며 완료 메시지에서 위치를 확인할 수 있습니다. 원래 상태로 돌아가야 할 때는 이 파일을 복원에 사용합니다.

현재 프로그램은 데이터베이스 버전 3~7의 백업을 복원할 수 있습니다. 오래된 백업에는 이후 추가된 인원·정원·시설·담당 강사 설정이 없을 수 있으므로 복원 후 확인하세요. 복원 전에 열려 있던 창에서 데이터 변경 메시지가 나오면 창을 닫고 앱을 다시 실행합니다.

## 12. 새 버전과 다른 컴퓨터로 이동

### 같은 컴퓨터에서 업데이트

1. **백업·복원**에서 현재 데이터를 백업합니다.
2. 실행 중인 앱을 닫습니다.
3. Windows는 [최신 설치 파일](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable-Setup.exe)을 내려받아 설치합니다. Mac은 [최신 배포 목록](https://github.com/ljwoo8942/academy-timetable/releases/latest)에서 앱을 받아 엽니다.
4. 기존 학기와 시간표가 표시되는지 확인합니다.

데이터는 실행 파일과 별도로 저장되므로 같은 사용자 계정에서는 이어서 사용할 수 있습니다. 새 프로그램이 데이터베이스를 갱신하면 이전 버전의 프로그램에서 열 수 없을 수 있으므로 업데이트 전 백업을 보관하세요.

Windows 앱은 Windows 설정의 앱 목록에서 **학원 시간표**를 선택해 제거할 수 있습니다. 앱을 제거해도 저장된 시간표 데이터는 유지됩니다.

### 다른 컴퓨터로 데이터 옮기기

1. 원래 컴퓨터에서 `.sqlite3` 백업을 저장합니다.
2. 새 컴퓨터에 맞는 실행 파일을 받아 실행합니다.
3. 백업 파일을 새 컴퓨터로 옮긴 뒤 **백업 파일에서 복원**을 사용합니다.
4. 새 컴퓨터의 기존 데이터도 교체되므로 필요하다면 먼저 별도로 백업합니다.

실행 파일만 복사해도 사용자가 입력한 시간표가 함께 옮겨지지는 않습니다. 데이터를 옮길 때는 백업·복원 기능을 사용하세요.

## 13. 자주 막히는 문제

| 상황 | 확인 방법 |
| --- | --- |
| Python이 설치되어 있지 않음 | 공개 배포의 설치 파일과 실행 파일에는 Python이 포함되어 있습니다. 별도로 Python을 설치할 필요 없이 `.exe` 파일을 실행합니다. |
| GPT·GitHub 로그인 화면이 나타남 | 이 프로그램은 로그인 기능이 없습니다. 내려받은 파일의 이름과 확장자를 확인하고 이 문서의 공식 설치 파일 링크에서 다시 받습니다. 링크 바로가기나 웹페이지 파일을 열고 있지 않은지도 확인합니다. |
| 인식할 수 없는 앱 또는 게시자를 확인할 수 없음 | Windows의 앱 확인 경고일 수 있습니다. 공식 배포에서 받은 파일인지 확인하세요. 이 버전은 배포 서명이 없으므로 경고가 계속 표시될 수 있으며, PC의 보안 정책에 따라 실행 허용 여부가 달라집니다. |
| 이 PC에서 실행할 수 없다고 표시됨 | Windows 버전과 64비트 여부를 확인합니다. 지원 기준은 Windows 10 1809 이상 x64 또는 Windows 11 x64입니다. |
| 반이나 시간표가 보이지 않음 | 오른쪽 위 학기와 시간표 편집 화면의 반을 확인합니다. |
| 수업 과목을 고를 수 없음 | 해당 반의 시수 설정, 잔여 교시, 과목의 활성 상태를 확인합니다. |
| 원하는 강사가 후보에 없음 | 과목 관리의 담당 강사 설정을 확인합니다. |
| 수업이 저장되지 않음 | 표시된 이유에 따라 시간 중복, 강사 불가 시간, 잔여 시수, 연강 경계, 정원·시설, 잠금을 확인합니다. |
| 강의실이 자동 제안되지 않음 | 반 인원과 강의실 정원, 필수 시설, 빈 시간, 수업 잠금을 확인합니다. |
| 엑셀 시간표의 미리보기를 누를 수 없음 | 파일을 연 뒤 시간표가 들어 있는 시트를 직접 선택합니다. |
| 시간표에 추가 버튼이 비활성 상태임 | 미리보기의 오류를 모두 해결하고 추가할 수업이 있는지 확인합니다. 시트나 조건을 바꿨다면 다시 미리보기를 누릅니다. |
| 엑셀에서 수정한 내용이 앱에 보이지 않음 | 파일 수정은 자동 반영되지 않습니다. 수업 변경은 시간표 편집에서 수행하고 새 수업은 불러오기로 추가합니다. |
| 초안 검토에 확인 필요가 남음 | 상세 내용에 표시된 시수·가능 시간·강의실·인원 등을 해당 화면에서 확인하고 다시 검토합니다. |
| 복원 후 다른 창에서 저장할 수 없음 | 복원 전에 열어 둔 창을 닫고 앱을 다시 실행합니다. |

## 14. 현재 지원 범위

현재 사용할 수 있는 기능은 학기·기본 정보 관리, 반별 시수 설정, 월~토 수업 수동 편집, 담당 강사와 가능 시간 설정, 강사 시수 집계, 강의실 수동 배정과 자동 제안, 초안 검토, 엑셀 가져오기·내보내기, 백업·복원입니다.

수업 시간 자동 편성, 학생별 선택수업 검증, 교과별 시간대·동시 편성, 교과·수강기호별 강사 시수표, PDF 출력은 개발 예정입니다. 실제 운영에 사용하기 전에 학교·학원에서 적용하는 추가 규칙과 최종 시간표를 직접 확인하세요.
