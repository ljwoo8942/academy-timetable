# Academy Timetable

**재수종합반을 위한 수동·자동 혼합형 시간표 관리 시스템** (설계 단계)

재수종합반의 **반 × 요일 × 교시** 구조를 기준으로 과목별 주간 시수, 강사 가능 시간, 강의실을 관리하고, 관리자가 직접 고정한 수업을 유지하면서 남은 수업을 자동으로 배치하는 **Python 설치형 데스크톱 프로그램**입니다. 인터넷 없이 PC에서 실행하는 것을 기본으로 합니다.

> 종로학원 재수종합반과 유사한 교시제 운영을 참고한 **독립 프로젝트**입니다. 특정 학원의 공식 프로그램이 아니며 교시 시간과 시수는 캠퍼스 설정에 따라 다릅니다.

## 설계 문서

**[상세 시스템 설계서 보기](docs/DESIGN.md)**

설계서에는 다음 내용이 포함되어 있습니다.

- 교시표, 반, 과목 시수, 강사, 강의실 관리
- 수동 시간표 편집과 교시 잠금
- 제약조건 기반 자동 편성 및 부분 재배치
- 강사·학생·반·강의실 충돌 검증
- 시간표 버전 관리, 관리자 검토 및 확정
- 데이터베이스 관계, Python 서비스 인터페이스, 데스크톱 화면 구성
- 개발 로드맵과 필수 테스트 시나리오

## 핵심 처리 과정

~~~text
반/강사/과목/교시 등록
    ↓
반별 주간 과목 시수 설정
    ↓
관리자가 중요한 교시를 수동 배치 및 잠금
    ↓
남은 교시 자동 편성
    ↓
중복 및 시수 검증
    ↓
배치안 검토·수정
    ↓
시간표 확정·조회·출력
~~~

## 권장 기술 스택

| 영역 | 기술 |
| --- | --- |
| 언어 | Python |
| 데스크톱 GUI | PySide6 (Qt for Python) |
| 데이터베이스 | SQLite (로컬 파일) |
| 자동 편성 | Google OR-Tools CP-SAT |
| Excel 출력 | openpyxl |
| PDF·인쇄 | PySide6 Qt Print Support |
| 실행 파일 | PyInstaller (후속 Windows 배포) |

> 현재는 **설계 단계**이며 위 스택은 구현 계획입니다. 웹 브라우저·웹 서버·PostgreSQL을 사용하지 않으며 프로그램 소스와 실행 파일은 아직 작성되지 않았습니다.

## 구현 순서

1. PySide6 메인 창, SQLite 연결 및 교시표·반·강사·과목·강의실 CRUD
2. 반별 과목 시수 및 수동 편집 화면
3. 충돌 검증과 교시 잠금
4. 자동 편성 엔진과 미배치 진단
5. 배치안 검토, 버전 확정, PDF·Excel 출력 및 로컬 백업
6. 선택수업, 자습, 휴강·보강·모의고사 확장

상세 데이터 모델, 화면 명세, API, 검증 규칙 및 테스트 기준은 [docs/DESIGN.md](docs/DESIGN.md)를 참고하세요.
