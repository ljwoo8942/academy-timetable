# Academy Timetable — 개발 초기 버전

[원본 설계 저장소](https://github.com/ljwoo8942/academy-timetable)의 설계를 참고해 만드는 오프라인 Python 데스크톱 프로그램입니다. 기준 문서: `98d86188d08440d3685c3122c7b883fff381f71d`의 [상세 설계](docs/DESIGN.md)와 [원본 README](docs/REFERENCE_README.md).

현재는 **개발 초기 단계**입니다. 학기, 학기별 반, 강사, 과목, 강의실의 이름을 관리하고 새 학기에 기본 11교시를 생성합니다. 학기별 교시 시각은 월~금 공통으로 수정할 수 있습니다. 과목은 기록 보존을 위해 삭제 대신 활성 상태를 변경합니다. 학기 삭제 시 그 학기의 반과 교시표도 함께 삭제됩니다.

[시간표 편집]에서 반별 과목 주간 시수와 1회 수업 길이를 설정하고, 월~금 교시를 선택하여 수업을 배정·이동·삭제·잠금할 수 있습니다. 수업은 반·강사·강의실 중복과 목표 시수 초과를 막고, 2교시 연강의 점심·저녁 경계를 확인합니다. 강의실은 미배정으로 둘 수 있습니다. [강사 시수 관리]에서 수동 배정된 실제 교시 수를 강사·과목별로 확인할 수 있습니다. 기본 수업 길이는 2교시이며 이름이 정확히 `영어`인 과목은 1교시를 제안하고, 설정 화면에서 변경할 수 있습니다. 설정한 길이로 나누어떨어지는 시수만 허용합니다.

이 단계의 충돌 검사는 반 전체 수업, 강사, 강의실만 다룹니다. 학생별 선택수업, 강사 가능 시간, 교과별 시간대·동시 편성, 최종 검증은 지원하지 않으며 수동 입력이 모든 운영 규칙에 맞는다는 뜻이 아닙니다. 자동 편성, 교과·수강기호별 강사 시수표, 엑셀/PDF 출력, 백업, 설치형 패키지도 아직 구현되지 않았으므로 실제 운영용으로 사용하기에는 이릅니다. 기존 데이터를 유지하면서 데이터베이스를 버전 2로 갱신합니다.

## 개발 환경 실행

Python 3.9 이상과 인터넷 연결(최초 의존성 설치 시)이 필요합니다. 이후 프로그램은 로컬에서 동작합니다.

macOS/Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m academy_timetable
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m academy_timetable
```

SQLite 파일은 Qt의 사용자별 앱 데이터 디렉터리에 저장됩니다. 개발 테스트: `python -m unittest discover -s tests` (패키지 설치 후).
