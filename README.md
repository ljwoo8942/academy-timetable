# Academy Timetable

**재수종합반을 위한 수동·자동 혼합형 시간표 관리 시스템** (설계 단계)

재수종합반의 **반 × 요일 × 교시** 구조를 기준으로 과목별 주간 시수, 강사 가능 시간, 강의실을 관리하고, 관리자가 직접 고정한 수업을 유지하면서 남은 수업을 자동으로 배치하는 **Python 설치형 GUI 데스크톱 프로그램**입니다. 인터넷 없이 **Windows와 macOS에서 동일한 기능을 사용하는 것**을 기본으로 합니다.

> 종로학원 재수종합반과 유사한 교시제 운영을 참고한 **독립 프로젝트**입니다. 특정 학원의 공식 프로그램이 아니며 교시 시간과 시수는 캠퍼스 설정에 따라 다릅니다.

## 설계 문서

**[상세 시스템 설계서 보기](docs/DESIGN.md)**

설계서에는 다음 내용이 포함되어 있습니다.

- 교시표, 반, 과목 시수, 강사, 강의실 관리
- **국어 > 화법과 작문(화작) / 언어와 매체(언매)** 등 상위·세부 과목과 택1 선택 그룹 관리
- 수동 시간표 편집과 교시 잠금
- **수업 기본 길이: 일반 과목 2교시 연강, 영어는 1교시** (과목·반별 예외 설정)
- 제약조건 기반 자동 편성 및 부분 재배치
- **강사별 과목 배정 시수표**: 교과명·강사명·수강기호·세부 과목별 시수·합계 자동 계산
- 강사·학생·반·강의실 충돌 검증
- 시간표 버전 관리, 관리자 검토 및 확정
- **반별·강사별·강의실별 시간표를 편집 가능한 Excel(.xlsx) 파일로 출력**
- 데이터베이스 관계, Python 서비스 인터페이스, 데스크톱 화면 구성
- 개발 로드맵과 필수 테스트 시나리오

## 지원 운영체제

| 플랫폼 | 배포 형태 | 지원 목표 |
| --- | --- | --- |
| **Windows** | `.exe` 또는 설치 프로그램 | Windows 10/11 64비트, 최소 지원 버전은 의존성 검증 후 확정 |
| **macOS** | `.app` (선택적으로 `.dmg`) | Apple Silicon 및 Intel Mac, 최소 지원 버전은 검증 후 확정 |

두 플랫폼 모두 **PySide6 GUI, 수동·자동 시간표 편성, SQLite 저장, Excel(.xlsx)/PDF 출력, 백업·복원**을 동일하게 제공하도록 설계합니다. 한 개의 Python 코드베이스를 공유하지만 **Windows와 macOS용 실행 파일은 각 운영체제에서 별도 빌드**합니다. macOS 배포용 서명·공증은 릴리스 단계에서 검토합니다.

현재는 설계 단계이며 Windows·macOS 실행 파일이 이미 존재하거나 실제 플랫폼 테스트가 끝난 상태는 아닙니다.

## GUI 조작 방식

**모든 주요 기능은 PySide6 창에서 마우스와 키보드로 조작합니다.** 사용자는 터미널이나 Python 코드를 입력할 필요가 없습니다.

- [기본 정보 관리]에서 반·강사·강의실·과목·교시표 등록
- 시간표 화면의 셀 클릭/드래그로 수업 배정, 이동, 잠금
- **[자동 편성]** 버튼으로 남은 교시 자동 배치 후 관리자 검토
- **[검증] → [확정]**으로 운영 시간표 확정
- **[엑셀 저장]**으로 반별·강사별·강의실별 .xlsx 파일 저장
- **[PDF/인쇄]**, **[백업·복원]**도 GUI 대화상자로 처리

상세한 화면 흐름은 [GUI 화면 설계](docs/DESIGN.md#5-python-데스크톱-화면-설계)를 참고하세요.

## 세부 과목 및 선택 영역

- 국어 공통수업과 **화법과 작문(화작)**, **언어와 매체(언매)**를 구분합니다.
- 화작·언매처럼 학생/반이 선택하는 과목은 **선택 그룹(예: 택1)**으로 관리합니다.
- 같은 교시에 두 선택수업을 병렬 운영할 수 있지만 **학생·강사·강의실 중복은 차단**합니다.
- 국어 총 시수와 화작/언매 시수의 **이중 계산을 방지**합니다.
- GUI 시간표와 Excel(.xlsx)에 **국어(화작)**, **국어(언매)**처럼 세부 영역을 표시합니다.
- 교과 구분은 학기별로 설정할 수 있으며 특정 교육과정에 고정하지 않습니다.

## 확정 기본 교시표 (11교시)

| 교시 | 수업 시간 | 교시 | 수업 시간 |
| --- | --- | --- | --- |
| 1 | 08:30~09:20 | 7 | 15:40~16:30 |
| 2 | 09:30~10:20 | 8 | 16:40~17:30 |
| 3 | 10:30~11:20 | 9 | 18:40~19:30 |
| 4 | 11:30~12:20 | 10 | 19:40~20:30 |
| 5 | 13:30~14:20 | 11 | 20:40~21:30 |
| 6 | 14:30~15:20 | | |

- 모든 교시 50분. **점심: 12:20~13:30 / 저녁: 17:30~18:40**. 6~7교시 사이 휴식은 20분입니다.
- 일반 과목은 **2교시 연강**, 영어는 **1교시 단독**을 기본으로 합니다.
- 연강은 **4~5교시(점심 경계), 8~9교시(저녁 경계)**를 넘을 수 없습니다. 6~7교시는 20분 쉬는 시간을 포함해 기본 연강 허용입니다.
- 시간표 GUI와 Excel/PDF 출력 모두 이 교시표를 기본값으로 사용하며 학기별 수정은 가능합니다.

## 동시 편성 그룹과 교과 시간대

- **과목별 그룹**: 국어 문학 1그룹=A반, 2그룹=B반+C반처럼 구성하고, 같은 그룹의 반은 반드시 **같은 요일·교시**에 편성합니다.
- **서로 다른 교과 그룹은 같은 교시에 병렬 배치할 수 있습니다.** 예: 국어 문학 2그룹(B·C)과 수학 2그룹(D·E)을 월요일 1~2교시에 동시에 편성할 수 있습니다. 그룹번호가 같아도 다른 과목이면 독립 그룹입니다.
- **실제 강사·강의실·반 전체·수강 학생이 중복되면 불가**하며, 그룹번호나 과목명만으로는 충돌을 판정하지 않습니다.
- **예시**: 국어 문학 2그룹 B반(국현)·C반(국문)을 월요일 **1~2교시 2T 연강**으로 동시에 배정합니다. 강사·강의실은 반별로 지정하고 충돌을 검사합니다.
- **운영 요일**: 월요일~금요일.
- **국어·수학·영어**: 기본 1~4교시 안에 배정. 불가능할 때 **5교시 예외는 반당 주 1개 요일 이내**이며 영어 1T는 5교시 단독 배치 가능.
- **국어·수학의 2T 주의**: 4~5교시 연강은 점심 경계 때문에 불가하며, 5~6교시는 6교시까지 사용하므로 **관리자가 별도로 승인하지 않으면 자동 배치하지 않습니다**.
- **통합사회·통합과학**: 월~금 중 **5~6교시 2T 연강** 필수, **화요일·목요일 우선(선호)**. 여건에 따라 월·수·금 5~6교시 가능.
- 그룹 동시 배정과 과목별 시간 제약은 GUI 편집, 자동 생성, 강사 배정 시수 계산, 최종 시간표 및 Excel 출력에서 동일하게 적용합니다.

## 제작 개요(HWPX) 기반 운영 및 입력 흐름

- **학기별 반 구성:** 3~10개 반 설정. 실제 반명과 과목별 A/B/C 레벨은 별도로 구분합니다.
- **강사 기본정보:** 강사명, 교과·세부 과목, 수강기호, 계획 수업시수, 최종 배정 시수를 조회합니다.
- **강사 가능 시간:** 월~금 **1~11교시 체크 표**에서 가능/불가/미설정을 설정합니다. 원본 양식의 토·일 열은 현재 정규 편성 범위가 아닙니다.
- **Excel 일괄 가져오기:** 교과명·과목명·반(레벨)·수업시간/시수·강사명·수강기호를 불러오며, 열 의미 매핑·미리보기·오류 확인 후 반영합니다.
- **강의실은 사후 배정:** 먼저 강사·반·과목·교시를 편성하고 이후 강의실을 지정합니다. 강의실 배정이 끝나고 검증에 통과해야 최종 시간표를 확정합니다.
- **하루 주요 과목 혼합:** 반별로 국어·수학·영어가 있는 날에는 **서로 다른 주요 교과 최소 2종**을 배치합니다. 국어만·수학만·영어만 있는 요일은 오류로 표시합니다.
- **기존 규칙 유지:** 일반 과목 2교시 연강/영어 1교시, 과목별 동시 그룹, 국수영 오전 우선, 통합사회·통합과학 5~6교시(화·목 선호).

원본 예시의 '수업시간' 숫자 1·2·4는 주간 총 교시인지 1회 수업 길이인지 명확하지 않아 **엑셀 업로드 시 입력 의미 확인**을 요구합니다. '수업시수/최종수업시수' 정의 역시 계획값과 배정 결과를 구분하되 확인이 필요합니다.

## 기본 수업 편성 규칙

- **국어·수학·탐구 등 일반 과목: 연속 2교시를 한 수업으로 배치**
- **영어 및 하위 영어 과목: 1교시를 한 수업으로 배치**
- 교시제 프로그램이므로 '2시간 연강'은 기본적으로 **2교시 연강**으로 해석합니다(각 교시 실제 분 수는 운영자가 설정).
- 강사·강의실·반·선택 그룹은 연강 전체에서 동일해야 하며 점심/휴식 슬롯을 가로지를 수 없습니다.
- 자동 편성 및 수동 수정 모두 묶음 단위로 동작하고, 강사 배정 시수표는 2교시 연강을 **2시수**로 집계합니다.
- 과목별 주간 시수가 연강 길이에 나누어떨어지지 않는 경우 경고하며, 별도 예외를 승인한 경우에만 1교시 잔여 수업을 허용합니다.

## 강사별 배정 시수 현황

- 첨부된 강사 시수표와 같이 **교과명 | 강사명 | 수강기호 | 세부 과목별 배정시수 | 합계** 형태로 조회합니다.
- 반별 시간표를 편집하거나 자동 편성하면 강사별 교시 수를 **자동 재계산**하고, 목표 시수 대비 잔여·초과를 확인합니다.
- 국어의 화작/언매를 포함한 세부 과목 열은 등록 정보에 맞춰 동적으로 표시하며 상위·하위 과목 시수는 이중 계산하지 않습니다.
- **강사_배정시수 시트**를 편집 가능한 Excel(.xlsx)로 저장하고, 강사별·과목별·전체 합계가 맞는지 검증합니다.

## 핵심 처리 과정

~~~text
반/강사/과목/교시 등록
    ↓
반별 주간 과목 시수 설정
    ↓
관리자가 중요한 교시를 수동 배치 및 잠금
    ↓
남은 교시 자동 편성
    ↓
중복 및 시수 검증
    ↓
배치안 검토·수정
    ↓
시간표 확정·조회·출력
~~~

## 권장 기술 스택

| 영역 | 기술 |
| --- | --- |
| 언어 | Python |
| 데스크톱 GUI | PySide6 (Qt for Python) |
| 데이터베이스 | SQLite (로컬 파일) |
| 자동 편성 | Google OR-Tools CP-SAT |
| Excel 출력 | openpyxl |
| PDF·인쇄 | PySide6 Qt Print Support |
| 실행 파일 | PyInstaller (Windows .exe / macOS .app 각각 빌드 예정) |

> 현재는 **설계 단계**이며 위 스택은 구현 계획입니다. 웹 브라우저·웹 서버·PostgreSQL을 사용하지 않으며 프로그램 소스와 실행 파일은 아직 작성되지 않았습니다.

## Excel(.xlsx) 시간표 출력

- **반별·강사별·강의실별 또는 전체 시간표**를 선택하여 .xlsx로 저장
- 반이나 강사별로 시트를 나누고 과목 색상, 교시·시간 헤더, 연속 수업을 표시
- A4 가로 인쇄 설정과 전체 배정 목록·과목 시수 요약 시트 지원
- **엑셀에서 직접 셀을 수정할 수 있는 파일**로 출력
- Excel이 없어도 Python openpyxl로 생성
- 내보낸 파일을 수정해도 SQLite 원본에 자동 반영되지는 않음(가져오기는 향후 기능)

상세 요구사항과 테스트 기준은 [설계문서](docs/DESIGN.md)의 12장을 참고하세요.
