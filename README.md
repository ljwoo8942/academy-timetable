# Academy Timetable — 개발 초기 버전

[원본 설계 저장소](https://github.com/ljwoo8942/academy-timetable)의 설계를 참고해 만드는 오프라인 Python 데스크톱 프로그램입니다. 기준 문서: `98d86188d08440d3685c3122c7b883fff381f71d`의 [상세 설계](docs/DESIGN.md)와 [원본 README](docs/REFERENCE_README.md).

## 사용 설명서

**[프로그램 사용 설명서 읽기](docs/USER_GUIDE.md)** — 처음 시작하기, 화면별 조작, 엑셀 시간표 불러오기, 강의실 배정, 백업·복원을 단계별로 안내합니다. GitHub 로그인 없이 읽을 수 있습니다.

## 다운로드 및 실행

**GitHub 계정이나 로그인 없이** 아래 링크에서 운영체제에 맞는 최신 실행 파일을 받으세요. [전체 배포 목록](https://github.com/ljwoo8942/academy-timetable/releases)에서도 다운로드할 수 있습니다.

| 운영체제 | 다운로드 | 실행 |
| --- | --- | --- |
| Windows 10 1809 이상 x64 · Windows 11 | [AcademyTimetable-Setup.exe 설치 파일 다운로드](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable-Setup.exe) | 파일을 더블클릭하고 **설치 → 완료**를 누릅니다. 완료 화면의 앱 실행을 체크하면 바로 열립니다. |
| Apple Silicon Mac | [AcademyTimetable-macOS-arm64.zip 다운로드](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable-macOS-arm64.zip) | 압축을 푼 뒤 `학원 시간표.app`을 더블클릭합니다. |

**Python이 없는 PC에서도 실행됩니다.** 설치 파일 안에 Python 실행 환경과 필요한 라이브러리가 포함되어 있어 따로 Python을 설치하거나 GPT·GitHub에 로그인할 필요가 없습니다. Windows는 현재 사용자 폴더에 설치하고 바탕화면과 시작 메뉴에 **학원 시간표** 바로가기를 만듭니다. 설치 후 인터넷 연결도 필요 없습니다.

Windows 지원 기준은 [Qt의 지원 조건](https://doc.qt.io/qt-6/supported-platforms.html)에 맞춘 **Windows 10 버전 1809(빌드 17763) 이상 64비트와 Windows 11 x64**입니다. `Win + R → winver`에서 Windows 버전을 확인할 수 있습니다. Windows 10 초기 버전과 32비트 Windows는 지원하지 않습니다.

설치 없이 실행하려면 [AcademyTimetable.exe](https://github.com/ljwoo8942/academy-timetable/releases/latest/download/AcademyTimetable.exe)를 받을 수 있습니다. 새 버전으로 바꿀 때는 앱을 닫고 새 설치 파일을 실행합니다. 학원 데이터는 별도 사용자 앱 데이터 폴더에 저장되며 재설치나 앱 제거 시에도 유지합니다. 중요한 데이터는 먼저 **백업·복원**에서 백업하세요.

다운로드 파일은 개발 확인용이며 Windows 배포 서명과 macOS 공증은 제공하지 않습니다. Windows의 **인식할 수 없는 앱** 또는 **게시자를 확인할 수 없음**은 앱 확인에 관한 보안 경고이며 GPT 로그인이나 Python 설치로 해결되는 문제가 아닙니다. 경고가 표시되면 다운로드 출처와 [설명서의 실행 문제 안내](docs/USER_GUIDE.md#13-자주-막히는-문제)를 확인하세요.

다운로드한 뒤에는 인터넷 연결이나 GitHub 로그인 없이 사용할 수 있습니다. `main`의 Windows·Mac 테스트와 빌드가 모두 통과하면 실행 파일이 공개 Releases에 자동 갱신됩니다.

처음 실행했다면 오른쪽 위 **사용 방법 → 처음 시작하기**에서 예시 학기와 수업을 따라 만들어 보세요. 이미 사용 중이라면 **백업·복원**에서 현재 데이터를 백업할 수 있습니다.

창 제목에서 실행 중인 버전을 확인할 수 있습니다. 시작 실패와 처리하지 못한 Python 오류는 사용자별 앱 데이터 폴더의 `academy-timetable.log`에 기록하며 오류 대화상자에 로그 위치를 표시합니다. 로그에는 버전과 실행 환경, 오류 상세가 포함됩니다.

## 앱에서 업데이트

화면 오른쪽 위 **업데이트**를 누르면 로그인 없이 GitHub 공개 배포를 확인합니다. 새 버전이 표시되면 **업데이트 설치**를 누르세요. 다운로드와 SHA-256 검증을 마친 뒤 현재 데이터를 `before_update_...sqlite3`로 자동 백업하고 앱을 종료해 교체·재실행합니다. 설치형 Windows 앱은 설치 프로그램으로 갱신하고, 무설치형은 실행 중인 `.exe`를 같은 위치에서 교체합니다. Apple Silicon Mac은 현재 `.app`을 교체합니다. 같은 버전 번호의 새 배포도 빌드 정보로 구별합니다.

저장하지 않은 교시표는 먼저 저장하고 다른 앱 창은 닫아 주세요. 확인·다운로드 중에는 취소할 수 있고 인터넷 연결 실패나 파일 검증 실패 시 앱을 교체하지 않습니다. Mac 앱과 무설치형 Windows 파일의 폴더에는 쓰기 권한이 필요합니다. 데이터와 업데이트 전 백업은 실행 파일과 별도로 유지됩니다.

이 기능이 없는 이전 앱은 최신 설치 파일을 한 번 직접 받아 설치해야 합니다. 이후에는 앱 안에서 업데이트할 수 있습니다. 소스 실행에서는 앱 파일을 자동 교체하지 않습니다. [업데이트 상세 안내](docs/USER_GUIDE.md#앱-안에서-업데이트)

## 주요 기능

현재는 **개발 초기 단계**입니다. 학기, 학기별 반, 강사, 과목, 강의실의 이름을 관리하고 새 학기에 기본 11교시를 생성합니다. 학기별 교시 시각은 월~토 공통으로 수정할 수 있습니다. 과목은 기록 보존을 위해 삭제 대신 활성 상태를 변경합니다. 학기 삭제 시 그 학기의 반과 교시표도 함께 삭제됩니다.

앱 오른쪽 위 **사용 방법**에서 처음 등록하는 예시와 기능별 안내를 읽을 수 있습니다. 목차에서 필요한 항목을 선택하세요.

[과목 관리 → 교과 설정]에서 문학·독서를 `국어`, 대수를 `수학`에 연결한 뒤 [과목별 반 설정 → + 추가]에서 `국어 A`, `국어 B`, `수학 A` 등을 만듭니다. **교과 단위**는 그 교과에 연결된 과목들을, **등록 과목 단위**는 선택한 한 과목만 배정할 수 있습니다. 예를 들어 `문학 A`를 등록 과목 단위로 설정하면 문학만 배정합니다. 반 이름은 학기 안에서 중복할 수 없습니다. 기존 반은 과목 제한이 없는 **공통 반**으로 유지되며 **반 기준 설정**으로 변경합니다. 기존 시수와 맞지 않는 기준 변경은 차단합니다. [자세한 설정 순서](docs/USER_GUIDE.md#과목별-반-설정)를 참고하세요.

[시간표 편집]에서 반별 과목 주간 시수와 1회 수업 길이를 설정하고, 월~토 교시를 선택하여 수업을 배정·이동·삭제·잠금할 수 있습니다. 수업은 반·강사·강의실 중복과 목표 시수 초과를 막고, 2교시 연강의 점심·저녁 경계를 확인합니다. 강의실은 미배정으로 둘 수 있습니다. [강사 시수 관리]에서 수동 배정된 실제 교시 수를 강사·과목별로 확인할 수 있습니다. 기본 수업 길이는 2교시이며 이름이 정확히 `영어`인 과목은 1교시를 제안하고, 설정 화면에서 변경할 수 있습니다. 설정한 길이로 나누어떨어지는 시수만 허용합니다.

상단 [엑셀 가져오기 → 기본 정보 가져오기]에서 `.xlsx` 파일과 시트를 선택하고, 첫 행의 열을 반·강사·과목·강의실 이름에 직접 연결할 수 있습니다. 반 열은 실제 반 이름일 때만 선택해야 하며 현재 학기에 등록됩니다. 모든 원본 열과 행별 오류를 미리 확인한 뒤 오류가 없을 때 전체를 한 번에 저장합니다. 같은 이름은 기존 항목을 유지하며 중복 생성하지 않습니다. 비활성 과목, 수식과 숫자 이름은 오류로 표시됩니다. 교과·레벨·수강기호·시수 열은 표시만 하고 저장하지 않습니다. 원본 파일은 변경하지 않습니다.

기본 정보 가져오기는 데이터 5,000행, 256열, 제목을 포함한 전체 50,000셀 이내를 읽습니다. 서식만 적용된 빈 영역도 범위에 포함될 수 있으므로 범위 초과 안내가 나오면 필요한 영역만 별도 파일로 저장해 선택하세요.

[엑셀 가져오기 → 시간표 불러오기]에서 `.xlsx` 파일을 열고 시간표가 있는 **시트 하나를 직접 선택**합니다. 앱으로 내보낸 파일은 `전체_배정목록`을 고르면 됩니다. 요일·반이 가로로 놓이고 과목·강사기호가 두 행씩 짝을 이루는 선행반 격자 시간표도 읽을 수 있습니다. 행별로 직접 만든 파일은 수업 한 건이 한 행에 들어가야 하며 `반`, `과목`, `강사`, `요일`, `시작 교시` 열이 필요합니다. `강의실`, `종료 교시`, `시수`, `잠금`은 선택입니다. 종료 교시와 시수를 모두 비우면 1교시로 처리합니다. 미리보기에 추가·중복·오류가 표시되며 오류가 없는 경우에만 현재 학기에 추가합니다. 새 반·과목·강사·강의실은 등록하고, 시수 설정이 없는 반·과목의 목표는 불러온 교시 합계로 만듭니다. 기존 수업과 시수 설정, 학기의 교시 시각은 유지합니다.

상단 [엑셀 내보내기]에서 현재 학기의 시간표 초안을 `.xlsx`로 저장합니다. 반별·강사별·강의실별 시간표, 전체 배정 목록, 반별 과목 시수와 강사 배정 시수가 포함됩니다. 2교시 연강은 두 교시에 표시하고, 강의실 미배정 수업도 표시합니다. 파일은 엑셀에서 수정할 수 있지만 수정 내용이 프로그램에 자동 반영되지는 않습니다. 교시표에 저장되지 않은 변경이 있으면 저장된 교시 시각으로 출력할지 확인합니다.

[강사 가능 시간]에서 학기·강사별 월~토 교시를 가능·불가·미설정으로 저장합니다. 불가 교시는 수동 배정을 차단하고, 이미 배정된 교시를 불가로 변경하는 것도 막습니다. 미설정은 확인되지 않은 상태로 수동 배정은 가능하며, 이후 자동 편성에서는 미설정을 배정 후보로 사용하지 않아야 합니다.

[과목 관리]에서 과목을 선택하고 **담당 강사 설정**을 눌러 해당 과목을 맡을 수 있는 강사를 체크합니다. 모든 학기에 적용되며, 설정한 과목은 등록된 담당 강사에게만 배정할 수 있습니다. 모두 해제하면 기존처럼 등록된 강사 중에서 수동 배정할 수 있습니다. 변경 전에 저장한 수업은 유지되며, 담당 강사가 맞지 않는 수업은 [초안 검토]에서 확인할 수 있습니다.

[초안 검토]에서 저장된 시간표의 반 수, 교시표, 시수 차이, 반·강사·강의실 중복, 담당 강사 불일치, 강사 불가·미설정 시간과 강의실 미배정을 조회합니다. 결과는 읽기 전용이며, 미설정 시간이나 미배정 수업은 확인 필요로 표시합니다. 검토하지 않는 규칙은 결과가 없어도 통과한 것으로 볼 수 없습니다.

[강의실 배정]에서 선택 학기의 저장된 수업을 조회하고 미배정 수업부터 강의실을 지정할 수 있습니다. 수업 전체 교시에 비어 있는 강의실을 선택해 저장하거나 `미배정`으로 되돌립니다. 저장할 때 중복 여부를 다시 확인하며, 수업의 시간과 강사는 유지합니다. 잠긴 수업은 시간표 편집에서 잠금을 해제해야 변경할 수 있습니다.

[과목별 반 설정]의 **인원 설정**과 [강의실 관리]의 **정원 설정**에서 인원을 입력합니다. `0`을 입력하면 미설정으로 저장됩니다. 두 값이 모두 설정되면 반 인원보다 정원이 작은 강의실은 후보에서 제외하고 시간표 편집에서도 배정을 차단합니다. 인원이나 정원 변경으로 기존 배정에 문제가 생기면 [초안 검토]에서 확인할 수 있습니다. 어느 한 값이 미설정이면 배정할 수 있고 검토 결과에 확인 필요가 표시됩니다.

[과목 관리]와 [강의실 관리]의 **시설 설정**에서 각각 필수 시설과 보유 시설을 등록합니다. 시설 이름은 줄바꿈이나 쉼표로 구분하고, 양쪽에서 같은 이름을 사용하세요. 앞뒤 공백과 대소문자는 비교에 영향을 주지 않습니다. 필수 시설을 모두 갖춘 강의실만 배정할 수 있습니다. 시설 정보가 비어 있는 강의실은 등록된 보유 시설이 없는 것으로 처리합니다. 설정 변경으로 기존 수업의 시설이 부족해지면 [초안 검토]에서 부족한 시설 이름을 확인할 수 있습니다.

[강의실 배정]의 **자동 제안**에서 현재 학기의 미배정 수업에 대해 제안 강의실과 미배정 사유를 확인합니다. 잠긴 수업과 반 인원이 미설정인 수업은 건너뛰고, 정원이 확인되고 필수 시설을 갖춘 강의실이 수업 전체 교시에 비어 있을 때만 제안합니다. 후보가 적은 수업부터 배정하므로 미배정 수업은 남을 수 있습니다. **제안 적용**을 누르면 제안이 유효한지 다시 확인하고 한 번에 저장합니다. 기존 강의실, 수업 시간, 강사는 유지합니다.

[백업·복원]에서 저장된 모든 학기와 시간표를 `.sqlite3` 파일로 백업하고 복원할 수 있습니다. 복원은 현재 데이터를 교체하므로 확인 대화상자를 거칩니다. 복원 전 현재 데이터는 앱 데이터 폴더에 `before_restore_...sqlite3`로 자동 보관되며, 복원 완료 메시지에서 위치를 확인할 수 있습니다. 데이터베이스 버전 3~8 백업을 복원할 수 있습니다. 버전 3 백업에는 반 인원과 강의실 정원이 없고, 버전 3·4 백업에는 시설 정보가 없으며, 버전 3~5 백업의 담당 강사 설정은 미설정으로 복원됩니다. 다른 프로그램 창의 저장되지 않은 변경은 먼저 저장하고 창을 닫으세요. 복원 전에 열려 있던 창에서는 복원 이후 저장이 차단되므로 프로그램을 다시 시작해야 합니다.

이 단계의 충돌 검사는 반 전체 수업, 반 기준과 과목의 일치, 강사, 강의실, 담당 강사 불일치, 강사 불가 시간, 강의실 정원 및 필수 시설을 다룹니다. 과목별 반은 독립된 반이므로 다른 반끼리 같은 시간에 수업을 둘 수 있으나 강사·강의실 중복은 계속 차단합니다. 학생별 선택수업, 교과별 시간대·동시 편성, 최종 검증은 지원하지 않으며 수동 입력이 모든 운영 규칙에 맞는다는 뜻이 아닙니다. 수업 시간 자동 편성, 수강기호를 포함한 엑셀 가져오기, 교과·수강기호별 강사 시수표, PDF 출력은 개발 예정입니다. 기존 데이터를 유지하면서 데이터베이스를 버전 8로 갱신합니다. 갱신한 데이터베이스는 이전 버전의 프로그램에서 열 수 없습니다.

## macOS 앱 빌드

아래 개발 환경을 준비한 뒤 프로젝트 폴더에서 실행하세요.

```sh
.venv/bin/python -m pip install 'PyInstaller==6.22.3'
bash scripts/build-macos.sh
```

Finder에서 `dist/학원 시간표.app`을 더블클릭하면 터미널이나 별도의 Python 설치 없이 실행됩니다. 앱은 빌드한 Mac의 아키텍처를 대상으로 하며 개발 환경 실행과 같은 사용자 데이터 위치를 사용합니다. 코드 변경을 확인할 때는 실행 중인 앱을 닫고 다시 빌드한 뒤 같은 앱을 열면 됩니다.

## Windows 실행 파일 빌드

Windows x64의 PowerShell에서 개발 환경과 [Inno Setup 6.5 이상](https://jrsoftware.org/isinfo.php)을 준비한 뒤 프로젝트 폴더에서 실행하세요. Inno Setup은 기본 경로인 `C:\Program Files (x86)\Inno Setup 6`에 설치합니다. 아래 도구는 실행 파일을 만드는 개발자에게만 필요합니다.

```powershell
.venv\Scripts\python.exe -m pip install PyInstaller==6.22.3
.\scripts\build-windows.ps1
```

완성된 설치 파일은 `dist\AcademyTimetable-Setup.exe`, 설치 없이 실행하는 파일은 `dist\AcademyTimetable.exe`에 저장됩니다. 둘 다 Python 실행 환경을 포함합니다.

## 개발 환경 실행

Python 3.9 이상과 인터넷 연결(최초 의존성 설치 시)이 필요합니다. 이후 프로그램은 로컬에서 동작합니다. 이전 개발 환경을 사용 중이라면 `pip install -e .`을 다시 실행해 엑셀 기능 의존성을 설치하세요.

macOS/Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m academy_timetable
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m academy_timetable
```

SQLite 파일은 Qt의 사용자별 앱 데이터 디렉터리에 저장됩니다. 개발 테스트: `python -m unittest discover -s tests` (패키지 설치 후).
